      gettime()

      What is gettime? 🤔

      The gettime() function retrieves specified numeric information about the current system time from the server operating system.

      By passing a designated time format constant, you can check specific hours, months, years, or retrieve the current date formatted directly as an integer. This is the defacto standard for scheduling specific happy hour events, day-of-the-week dungeons, and daily reset mechanics.

      Syntax of gettime? 📜

      • gettime(<type>)

      Syntax Parameter Explanation 🧩

      Constant Name Return Value Class Description
      DT_SECOND 0 - 59 Current second within the active minute.
      DT_MINUTE 0 - 59 Current minute within the active hour.
      DT_HOUR 0 - 23 Current hour in 24-hour format.
      DT_DAYOFWEEK 0 - 6 Day of the week. Predefined constants are: SUNDAY (0), MONDAY (1), TUESDAY (2), WEDNESDAY (3), THURSDAY (4), FRIDAY (5), and SATURDAY (6).
      DT_DAYOFMONTH 1 - 31 Active day number within the month.
      DT_MONTH 1 - 12 Month of the year. Predefined constants are: JANUARY (1) through DECEMBER (12).
      DT_YEAR Integer Full four-digit numerical year (e.g. 2026).
      DT_DAYOFYEAR 1 - 366 Day number out of the full year.
      DT_YYYYMMDD Integer (YYYYMMDD) Combines numerical elements into a unified integer (e.g., May 30, 2026 becomes 20260530). Perfect for tracking absolute daily rollover deadlines.

      Return Values ↩️

      • Returns the corresponding **integer** value mapped to the supplied constant.
      • Returns **-1** if an invalid type format parameter is provided.

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= Weekly Dungeon Guard Happy-Hour Gatekeeper
//===== By: rAthena AI Assistant ============================
//= Showcases gettime() to restrict access and unlock buffs
//============================================================
prontera,164,188,4	script	Happy Hour Guard	803,{
    mes "^0000FF[Happy Hour Guard]^000000";
    mes "Greetings, warrior! I coordinate the happy-hour training chambers.";
    
    // Check if current day of the week is Saturday (6) or Sunday (0)
    set .@day, gettime(DT_DAYOFWEEK);
    if (.@day == SATURDAY || .@day == SUNDAY) {
        mes "Aha! We are in the middle of our ^00FF00Weekend Double EXP Bonus^000000 event!";
        next;
    } else {
        // Happy hours are scheduled from 18:00 (6 PM) to 20:00 (8 PM) on weekdays
        set .@hour, gettime(DT_HOUR);
        if (.@hour >= 18 && .@hour < 20) {
            mes "Congratulations! You have arrived during the weekday Happy Hour!";
            next;
        } else {
            mes "The happy training gate has not opened yet.";
            mes "Weekday Training hours: ^FF000018:00 - 20:00 (6 PM - 8 PM)^000000.";
            mes "Your system clock reads: ^0055FF" + .@hour + ":" + sprintf("%02d", gettime(DT_MINUTE)) + "^000000.";
            close;
        }
    }

    mes "^0000FF[Happy Hour Guard]^000000";
    mes "Let's teleport you inside now! Go claim your exp glories!";
    next;
    warp "pvp_n_01", 100, 100;
    end;
}

      In this script:

      The Guard NPC utilizes robust calendar calculations:

      • The function gettime(DT_DAYOFWEEK) queries the current weekday and evaluates it against standard global constants (SATURDAY / SUNDAY).
      • If it's a weekday, gettime(DT_HOUR) verifies if the server's local clock hour falls within 18:00 and 19:59.
      • This enables dynamic systems without complex backend background loops, optimizing thread utilization on the emulator.
