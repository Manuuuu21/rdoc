      jobcanentermap

      What is jobcanentermap? 🤔

      The jobcanentermap command returns true (1) if a particular class ID (Job) is permitted to access/enter the specified map name, and false (0) otherwise.

      This references standard restrictions configured in the server's db tables under db/[pre-]re/job_noenter_map.txt. This is incredibly useful for restricting specific classes (e.g., forbidding high-tier jobs or baby jobs) from accessing certain specialty maps, custom PvP arenas, or event zones.

      Syntax of jobcanentermap 📜

      • jobcanentermap("<mapname>"{,<JobID>});

      Parameters 🎯

      • "<mapname>": The target map name to check (e.g., "prontera", "sec_pri").
      • <JobID> (Optional): The class Job constant (such as Job_Novice, Job_Swordman) or variables like Class, BaseJob, or BaseClass. If no player character is currently attached, this parameter **MUST** be explicitly specified. Defaults to the active class ID of the invoking player if omitted.

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= Restricted Map Warp demonstrator
//============================================================
prontera,150,150,4	script	Zone Portal Check	99,{
    mes "^0000FF[Portal Guard]^000000";
    mes "Greetings. Do you wish to enter the Special Training Grounds?";
    next;
    
    // Check if the current player's class is permitted to enter the "force_map" zone
    if (!jobcanentermap("force_map", Class)) {
        mes "^0000FF[Portal Guard]^000000";
        mes "I am sorry! Your profession is legally restricted from entering this facility.";
        close;
    }
    
    mes "^0000FF[Portal Guard]^000000";
    mes "Verification succeeded! Proceeding to warp.";
    close2;
    warp "force_map", 50, 50;
    end;
}

      In this script:

      • On line 9, jobcanentermap("force_map", Class) evaluates if the player's Class is permitted to teleport onto "force_map", filtering out restricted personnel before warping.
