      areamobuseskill

      What is areamobuseskill? 🤔

      This command will make all monsters of the specified <mob id> or <mob name> in the specified area use the specified skill. <map name>, <x>, and <y> define the center of the area, which extending <range> cells in each direction (ex: a range of 3 would create a 7x7 square). The skill can be specified by <skill id> or <skill name>. <cast time> is in milliseconds (1000 = 1 second), and the rest should be self-explanatory.

      Syntax of areamobuseskill 📜

      • areamobuseskill "<map name>",<x>,<y>,<range>,<mob id>,<skill id>,<skill level>,<cast time>,<cancelable>,<emotion>,<target type>;
      • areamobuseskill "<map name>",<x>,<y>,<range>,<mob id>,"<skill name>",<skill level>,<cast time>,<cancelable>,<emotion>,<target type>;
      • areamobuseskill "<map name>",<x>,<y>,<range>,"<mob name>",<skill id>,<skill level>,<cast time>,<cancelable>,<emotion>,<target type>;
      • areamobuseskill "<map name>",<x>,<y>,<range>,"<mob name>","<skill name>",<skill level>,<cast time>,<cancelable>,<emotion>,<target type>;

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      "<map name>" String The name of the target map (e.g., "prontera").
      <x> Integer The X coordinate on the map.
      <y> Integer The Y coordinate on the map.
      <range> Integer The cell radius or range around the center coordinates.
      <mob id> Integer The monster database ID from mob_db.yml.
      <skill id> Integer The numeric skill ID from skill_db.yml.
      <skill level> Integer The level of the skill to cast or grant.
      <cast time> Integer Specifies the <cast time> parameter for areamobuseskill.
      <cancelable> Integer Specifies the <cancelable> parameter for areamobuseskill.
      <emotion> Integer Specifies the <emotion> parameter for areamobuseskill.
      <target type> Constant / Integer Specifies the <target type> parameter for areamobuseskill.
      "<skill name>" String The AegisName of the skill from skill_db.yml (e.g., "AL_HEAL").
      "<mob name>" String The monster's AegisName or display name.
      "<,>" String Specifies the <,> parameter for areamobuseskill.

      Constants & Options ⚙️

      <target type> can be:

      Constant / Value Description
      0 self
      1 the mob's current target
      2 the mob's master
      3 random target

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= areamobuseskill Demonstration NPC
//= Demonstrates how to use areamobuseskill
//============================================================
prontera,150,150,4	script	AreamobuseskillDemo	100,{
    mes "[AreamobuseskillDemo]";
    // spawn 1 Shining Plant in the 5x5 area centered on (155,188)
        areamonster "prontera",153,186,157,190,"Shining Plant",1083,1;
        // make the plant cast level 10 Cold Bolt on a random target
        areamobuseskill "prontera",155,188,2,1083,"MG_COLDBOLT",10,3000,1,ET_KEK,3;
    close;
}

      In this script:

      • The script defines an NPC object on prontera (or the target map) that triggers when a player interacts with it.
      • It invokes areamobuseskill with the required arguments as specified in the rAthena scripting reference.
      • Any resulting state change, return value, or player/unit update is processed immediately within the active script execution context.
