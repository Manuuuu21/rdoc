      getmapxy()

      What is getmapxy? 🤔

      The getmapxy() function is used to locate a specific game object (such as a Player, NPC, or Pet) in the game world. It retrieves the entity's current map name, X-coordinate, and Y-coordinate, then assigns those values directly to the variables passed in as arguments.

      This function is incredibly powerful for tracking system mechanics, player-versus-player locating skills, target trackers, and interactive system NPCs that find hidden components.

      Syntax of getmapxy? 📜

      • getmapxy(<variable for map name>, <variable for x>, <variable for y>{, <type>, "<search value>"})

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      <variable for map name> String Variable The string variable (e.g. .@mapname$) that will receive the name of the map.
      <variable for x> Integer Variable The integer variable (e.g. .@mapx) that will receive the X coordinate.
      <variable for y> Integer Variable The integer variable (e.g. .@mapy) that will receive the Y coordinate.
      <type> (Optional) Constant The category of entity to locate. Defaults to BL_PC if omitted. Common constant targets are defined below.
      <search value> (Optional) String The name of the character, NPC, or pet to search for (required for finding non-player target systems).

      Target Type Constants (<type>) 🎯

      The following rAthena constants can be supplied in the fourth parameter to qualify the type of object to locate:

      Constant Name Target Entity Type Requirement
      BL_PC Player Character (Default) If search value is omitted, finds the invoking player. Otherwise, searches for the player named in search value.
      BL_NPC NPC Object Requires <search value> specifying the unique identity/display name of the target NPC (even if disabled via disablenpc).
      BL_PET Active Pet Finds the active pet belonging to the player.

      Return Values ↩️

      • Returns 0 if the entity search was successful, and coordinate assignments succeeded.
      • Returns -1 if the search failed (e.g. player is offline, target NPC does not exist) or if parameters passed are not valid writable variables.

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= Hide-and-Seek NPC Tracking System
//===== By: rAthena AI Assistant ============================
//= Showcases getmapxy() to find players and target NPCs
//============================================================
prontera,164,299,3	script	Nyah	730,{
    mes "^0000FF[Nyah]^000000";
    mes "Greetings! I am looking for my sister 'Meh' somewhere in the world.";
    mes "Let me try to locate her coordinates using my magical device.";
    next;

    // Search for an NPC named "Meh" of type BL_NPC
    if (getmapxy(.@mapname$, .@mapx, .@mapy, BL_NPC, "Meh") != 0) {
        mes "^0000FF[Nyah]^000000";
        mes "Oh no! My radar can't seem to find Meh anywhere in the kingdom!";
        close;
    }

    mes "^0000FF[Nyah]^000000";
    mes "Ah, I found her! My radar says she is stationed here:";
    mes "Map: ^00FF00" + .@mapname$ + "^000000";
    mes "Coordinates: ^FF0000X: " + .@mapx + ", Y: " + .@mapy + "^000000";
    next;

    mes "^0000FF[Nyah]^000000";
    mes "Would you like to be teleported directly to her locations?";
    next;

    if (select("Yes, warp me!:No thanks") == 1) {
        warp .@mapname$, .@mapx, .@mapy;
        end;
    }

    mes "^0000FF[Nyah]^000000";
    mes "No problem! Let me know if you change your mind.";
    close;
}

// Target NPC positioned elsewhere
morroc,120,85,3	script	Meh	730,{
    mes "^0000FF[Meh]^000000";
    mes "Ah, I love the sandy breeze of Morroc town center.";
    close;
}

      In this script:

      This search NPC illustrates clean variable assigning conventions via getmapxy():

      • The command getmapxy(.@mapname$, .@mapx, .@mapy, BL_NPC, "Meh") initiates a system lookup for the NPC tagged "Meh".
      • If "Meh" is running on the world server, the variables are populated as strings and integers cleanly, returning 0.
      • If it fails, a feedback warning is cleanly presented, ensuring scripts don't attempt to execute a blank warp instruction.
