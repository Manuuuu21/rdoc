      do

      What is do? 🤔

      The do...while is the only post-test loop structure available in this script language. With a post-test, the statements are executed once before the condition is tested. When the condition is true, the statement(s) are repeated. When the condition is false, control is transferred to the statement following the do...while loop expression.

      Example 2: counter-controlled loop

      Syntax of do 📜

      • do { <statement>; } while (<condition>);

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      <statement> (Optional) Statement A single script statement or a block of statements enclosed in { ... }.
      <condition> Expression A conditional expression that evaluates to non-zero (true) or zero (false).

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= do Demonstration NPC
//= Demonstrates how to use do
//============================================================
prontera,150,150,4	script	DoDemo	100,{
    mes "[DoDemo]";
    mes "This menu will keep appearing until you pick Cancel";
        do {
            .@menu = select("One:Two:Three:Cancel");
        } while (.@menu != 4);
    close;
}

      In this script:

      • The script defines an NPC object on prontera (or the target map) that triggers when a player interacts with it.
      • It invokes do with the required arguments as specified in the rAthena scripting reference.
      • Any resulting state change, return value, or player/unit update is processed immediately within the active script execution context.
      Example 2:
      //===== rAthena Script =======================================
//= do Demonstration NPC
//= Demonstrates how to use do
//============================================================
prontera,150,150,4	script	DoDemo	100,{
    mes "[DoDemo]";
    mes "This will countdown from 10 to 1.";
        .@i = 10;
        do {
            mes .@i;
            .@i -= 1;
        } while (.@i > 0);
    close;
}
