      query_sql, query_logsql

      What are query_sql, query_logsql? 🤔

      Executes an SQL query. A select query can fill array variables with up to 2 billion rows of values, and will return the number of rows (i.e. array size) or -1 on failure.

      Note that query_sql runs on the main database while query_logsql runs on the log database.

      Syntax of query_sql, query_logsql 📜

      • query_sql("your MySQL query"{, <array variable>{, <array variable>{, ...}}});
      • query_logsql("your MySQL query"{, <array variable>{, <array variable>{, ...}}});

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      "<your MySQL query>" String The SQL query string to execute against the MySQL/MariaDB server.
      <array variable> (Optional) Array An array variable to store column results returned by a SELECT query.

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= query_sql, query_logsql Demonstration NPC
//= Demonstrates how to use query_sql, query_logsql
//============================================================
prontera,150,150,4	script	QuerySqlDemo	100,{
    mes "[QuerySqlDemo]";
    .@nb = query_sql("select name,fame from "char" ORDER BY fame DESC LIMIT 5", .@name$, .@fame);
        mes "Hall Of Fame: TOP5";
        mes "1." + .@name$[0] + "(" + .@fame[0] + ")"; // largest fame value.
        mes "2." + .@name$[1] + "(" + .@fame[1] + ")";
        mes "3." + .@name$[2] + "(" + .@fame[2] + ")";
        mes "4." + .@name$[3] + "(" + .@fame[3] + ")";
        mes "5." + .@name$[4] + "(" + .@fame[4] + ")";
    close;
}

      In this script:

      • The script defines an NPC object on prontera (or the target map) that triggers when a player interacts with it.
      • It invokes query_sql with the required arguments as specified in the rAthena scripting reference.
      • Any resulting state change, return value, or player/unit update is processed immediately within the active script execution context.
