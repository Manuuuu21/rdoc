      instance_check_party()

      What is instance_check_party? 🤔

      This function checks if a party meets certain requirements, returning 1 if all conditions are met and 0 otherwise. It will only check online characters. The command returns 0 is the party ID does not exist.

      amount - number of online party members (default is 1). min - minimum level of all characters in the party (default is 1). max - maximum level of all characters in the party (default is max level in conf).

      Syntax of instance_check_party 📜

      • instance_check_party(<party id>{,<amount>{,<min>{,<max>}}})

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      <party id> Integer The unique ID of the target party.
      <amount> (Optional) Integer The quantity or amount to add, remove, or check.
      <min> (Optional) Integer Specifies the <min> parameter for instance_check_party.
      <max> (Optional) Integer Specifies the <max> parameter for instance_check_party.

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= instance_check_party Demonstration NPC
//= Demonstrates how to use instance_check_party
//============================================================
prontera,150,150,4	script	InstanceCheckPartyDemo	100,{
    mes "[InstanceCheckPartyDemo]";
    if (instance_check_party(getcharid(1),2,2,149)) {
        mes "Your party meets the Memorial Dungeon requirements.",
        mes "All online members are between levels 1-150 and at least two are online.";
        close;
    } else {
        mes "Sorry, your party does not meet requirements.";
        close;
    }
}

      In this script:

      • The script defines an NPC object on prontera (or the target map) that triggers when a player interacts with it.
      • It invokes instance_check_party with the required arguments as specified in the rAthena scripting reference.
      • Any resulting state change, return value, or player/unit update is processed immediately within the active script execution context.
