      jobchange

      What is jobchange? 🤔

      The jobchange command updates the class job of the calling character to a specified target job type.

      This is standard behavior heavily utilized inside Job Master NPCs, reincarnation or rebirth trials, and promotional events. It handles resetting job points and adjusting parameters automatically based on constants found in the rAthena source code.

      Syntax of jobchange 📜

      • jobchange <job number>{,<upper flag>{,<char_id>}};

      Parameters 🎯

      • <job number>: The numeric ID of the class to switch to. Constants (like Job_Swordman or Job_Novice) from src/map/script_constants.hpp can also be referenced.
      • <upper flag> (Optional): Selects class variations:
        • - 0: Normal/standard classes [Default]
        • - 1: Rebirth / High / Advanced classes
        • - 2: Baby classes
      • <char_id> (Optional): The character ID of the player to target. Defaults to the invoking player character if left unspecified.

      ⚠️ Note: Executes a permanent character-based variable save in 'jobchange_level', storing the player's job level right before changing, which can be useful to verify later.

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= Job Changer NPC Demonstration
//============================================================
prontera,150,150,4	script	Job Master	99,{
    mes "^0000FF[Job Master]^000000";
    mes "Greetings! Do you wish to switch your profession?";
    next;
    
    set .@menu, select("Become a Swordman:Become a Baby Swordman:Become a High Swordman:Cancel");
    if (.@menu == 4) {
        mes "^0000FF[Job Master]^000000";
        mes "Come back when you are ready.";
        close;
    }
    
    if (.@menu == 1) {
        // Change to Swordman (ID: 1) as Normal/Standard class
        jobchange 1, 0;
    } else if (.@menu == 2) {
        // Change to Swordman (ID: 1) as Baby class (upper flag: 2)
        jobchange 1, 2;
    } else if (.@menu == 3) {
        // Change to High Swordman (ID: 4002) as Rebirth/Advanced class
        jobchange 4002, 1;
    }
    
    mes "^0000FF[Job Master]^000000";
    mes "Congratulations! Your new class identity has been registered successfully.";
    close;
}

      In this script:

      • On line 16, jobchange 1, 0 changes the player's class to standard Swordman (job class ID 1).
      • On line 19, jobchange 1, 2 changes the player's class to Baby Swordman (job class ID 1 with the Baby sub-type).
      • On line 22, jobchange 4002, 1 changes the player's class to High Swordman (job class ID 4002, Rebirth class flag).
