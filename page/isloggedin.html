      isloggedin()

      What is isloggedin? 🤔

      The isloggedin() function checks if a specific player is currently active and logged into the server.

      In rAthena, you can check player status either purely by their **Account ID** (AID) or more precisely by combination of **Account ID** plus their **Character ID** (CID). Checking both is highly recommended when evaluating structures like parties or guilds where a player might have multiple distinct characters in the group, ensuring your checks are completely accurate.

      Syntax of isloggedin? 📜

      • isloggedin(<account id>)
      • isloggedin(<account id>, <char id>)

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      <account id> Integer The account number of the player to search for.
      <char id> (Optional) Integer The specific character ID. If supplied, the player is considered online only if they are active on this exact character.

      Return Values ↩️

      • Returns **1** if the specified player is active on the server.
      • Returns **0** if they are completely offline.

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= Guild / Party Assembly Registry
//= Showcases isloggedin() to count online members
//============================================================
prontera,160,185,4	script	Party Registrar	102,{
    mes "^0000FF[Party Registrar]^000000";
    mes "Greetings! Let me analyze your active party attendance.";
    next;

    if (!getcharid(1)) {
        mes "You must form or join a party first!";
        close;
    }

    // Retrieve global party parameters
    getpartymember getcharid(1), 1; // Fills $@partymemberaid and $@partymembercid arrays
    set .@total_members, $@partymembercount;
    set .@online_members, 0;

    for (set .@i, 0; .@i < .@total_members; set .@i, .@i + 1) {
        // Query both Account ID and Character ID to map exactly who is active
        if (isloggedin($@partymemberaid[.@i], $@partymembercid[.@i])) {
            set .@online_members, .@online_members + 1;
        }
    }

    mes "^0000FF[Party Registrar]^000000";
    mes "Party Name: ^00FF00" + getpartyname(getcharid(1)) + "^000000";
    mes "Registered headcount: " + .@total_members;
    mes "Currently Active Online: ^FF0000" + .@online_members + "^000000";
    close;
}

      In this script:

      The Party Registrar loops through each group member to perform a live scan:

      • Calling getpartymember on line 15 populates temporary arrays holding the account levels ($@partymemberaid) and specific character structures ($@partymembercid) of all group members.
      • Inside the loop starting on line 19, isloggedin($@partymemberaid[.@i], $@partymembercid[.@i]) is used to confirm presence.
      • Using both params is critical here because party setups could historically host multiple character records belonging to a single account; verifying by both IDs filters out offline clones perfectly.
