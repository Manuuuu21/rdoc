      setriding(), checkriding()

      What is setriding and checkriding? 🤔

      The setriding() command assigns or un-assigns class-specific mounted creatures (such as standard PecoPecos, GrandPecos, and Gryphons) from the target character. The companion checkriding() function returns whether they are mounted.

      Unlike carts and falcons, setriding has strict engine checks in place. **It will strictly fail** if the target player is not belonging to a class that is permitted to ride, and they must possess the active requirement skill "Riding" (KN_RIDING) loaded in their skill sheet. Depending on the class, the client automatically renders:

      • PecoPeco: Knight and Lord Knight classes.
      • GrandPeco: Crusader and Paladin classes.
      • Gryphon: Royal Guard classes.

      Syntax Specifications 📜

      • setriding {<flag>{, <char_id>}};
      • checkriding({<char_id>});

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      <flag> Integer Toggle state: Use 1 to mount the bird; use 0 to dismount and clear.
      <char_id> (Optional) Integer The character ID. If supplied, targets that specific player instead of the currently attached one.

      Return Values (checkriding) ↩️

      • Returns **1** if the character is currently riding an animal mount.
      • Returns **0** if they are on foot.

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= Stable Master & Gate restrictions
//= Showcases checkriding() and setriding() to enforce regulations
//============================================================
prontera,150,195,4	script	Stable Master	102,{
    mes "^0000FF[Stable Master]^000000";
    mes "Greetings! The military rules impose strict equestrian standards.";
    mes "No mounting is allowed inside royal buildings!";
    next;

    if (checkriding()) {
        mes "^0000FF[Stable Master]^000000";
        mes "Egad! Please dismount your bird immediately! Dismount now?";
        next;
        if (select("Dismount safely:Keep riding") == 1) {
            setriding 0; // Dismount mount
            mes "^0000FF[Stable Master]^000000";
            mes "Thank you! Feel free to enter our halls.";
        }
        close;
    }

    // Verify riding capabilities
    if (getskilllv("KN_RIDING") < 1) {
        mes "^0000FF[Stable Master]^000000";
        mes "You lack knightly Riding mastery (KN_RIDING) to board these mounts!";
        close;
    }

    mes "^0000FF[Stable Master]^000000";
    mes "Would you like me to summon your class mount?";
    next;

    if (select("Yes, bring mount:No, walk") == 1) {
        setriding 1; // Equips mount
        mes "^0000FF[Stable Master]^000000";
        mes "The stable doors open. Carry on!";
    }
    close;
}

      In this script:

      The Stable Master regulates castle entrance compliance:

      • We call checkriding() on line 11 to audit active mounts near gates.
      • If checked as active, calling setriding 0 on line 15 triggers visual dismounts.
      • We verify Riding competencies via KN_RIDING on line 22 before stables unlock.
      • If the user passes all compliance, calling setriding 1 on line 30 opens stable gates and deploys mounts.
