      recovery()

      What is recovery? 🤔

      The recovery() command fully restores the HP and SP of selected groups of characters (or even the entire server), while also reviving any fallen/dead player characters.

      This command is incredibly robust and is the standard way to heal/revive all active players after PvP guild castle sieges (WoE), upon completing instances/raids, or during live GM community events.

      Syntax of recovery 📜

      • recovery <type>{,<option>,<revive_flag>{,"<map name>"}};

      Target Types (<type>) 🎯

      Type Targets Selected Expected Option Value
      0 Single Individual Player Character database ID (Defaults to invoking player)
      1 Entire Party Members Party ID number (Defaults to invoking party)
      2 Entire Guild Members Guild ID number (Defaults to invoking guild)
      3 Map Zone population Target Map Name as string (e.g. "prontera")
      4 All active server players None (Uses revive_flag directly)

      Revive Flags (<revive_flag>) ⚙️

      Flag Action Executed
      1 Revive dead players AND fully heal all matches (HP and SP). [Default]
      2 Heal only living match players. Completely ignores dead players!
      4 Revive dead character targets and heal them, but ignore living targets entirely!

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= Ultimate Resurrection & Recovery Service
//= Demonstrates multiple recovery target and flag operations
//============================================================
prontera,150,160,4	script	Resurrector Master	99,{
    mes "^0000FF[Guild Priest]^000000";
    mes "Greetings. I can revive or restore whole structures instantly.";
    next;
    
    set .@sel, select("Revive Guild on Morocc Map:Fully Heal party members on Morocc only:Resurrect ALL servers-side dead:Cancel");
    
    if (.@sel == 1) {
        set .@guild, getcharid(2);
        if (.@guild == 0) {
            mes "Error: You are not inside a Guild list!";
            close;
        }
        // Recover option 2 (Guild), target guild ID, flag 1 (Revive and Heal) on map "morocc"
        recovery 2, .@guild, 1, "morocc";
        dispbottom "Guild recovery lines broadcasted on Morocc map!";
    } 
    else if (.@sel == 2) {
        set .@party, getcharid(1);
        if (.@party == 0) {
            mes "Error: You are not inside a Party list!";
            close;
        }
        // Recover option 1 (Party), target party ID, flag 2 (Heal living only) on map "morocc"
        recovery 1, .@party, 2, "morocc";
        dispbottom "Party healing buffers loaded on Morocc map!";
    } 
    else if (.@sel == 3) {
        // Recover option 4 (All), flag 4 (Dead only) 
        recovery 4, 4;
        dispbottom "Server-side global resurrect sequence executed!";
    }
    
    mes "^0000FF[Guild Priest]^000000";
    mes "Restorations completed!";
    close;
}

      In this script:

      • On line 18, recovery 2, .@guild, 1, "morocc" revives and heals all guild members of the specified guild ID, filtered down to only those currently situated on map morocc.
      • On line 28, recovery 1, .@party, 2, "morocc" heals living party members on morocc while skipping dead party members.
      • On line 33, recovery 4, 4 executes a server-wide target sequence, reviving every single dead player on the shard.
