      setmadogear(), checkmadogear()

      What is setmadogear and checkmadogear? 🤔

      The setmadogear() command boards or dismounts a Mechanic's armored Madogear Mech suit, supporting multiple visual chassis. The accompanying checkmadogear() function queries if the player is currently piloting one.

      Toggling a Mech suit is restricted strictly to the **Mechanic class line**, requiring the training skill "Mado Licence" (NC_MADOLICENCE) to be active, or else the toggle command fails immediately.

      Syntax Specifications 📜

      • setmadogear {<flag>{, <type>{, <char_id>}}};
      • checkmadogear({<char_id>});

      Syntax Parameter Explanation 🧩

      Note: The type argument requires client definitions configured for packet ranges greater than or equal to `PACKETVER_MAIN_NUM: 20191120` or `PACKETVER_RE_NUM: 20191106`.

      Parameter Type Description
      <flag> Boolean / Integer Toggle state: Use 1 (or true) to board; use 0 (or false) to dismount.
      <type> (Optional) Integer / Constant Assigns specific Mech visual index. Predefined constants are MADO_ROBOT (default) or MADO_SUIT.
      <char_id> (Optional) Integer The character ID. If supplied, targets that specific player instead of the currently attached one.

      Return Values (checkmadogear) ↩️

      • Returns **1** if currently piloting configured Madogear armor.
      • Returns **0** if on foot.

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= Mechanic Hangar Garage
//= Demonstrates checkmadogear() and setmadogear() with chassis constants
//============================================================
einbech,160,200,4	script	Hangar Mechanic	104,{
    mes "^0000FF[Hangar Mechanic]^000000";
    mes "Yo! Need to repair your chassis or reconfigure systems?";
    next;

    if (checkmadogear()) {
        mes "^0000FF[Hangar Mechanic]^000000";
        mes "Active Mech detected. Dismount for maintenance?";
        next;
        if (select("Dismount safely:Keep Mech online") == 1) {
            setmadogear false; // Dismount Mech suit
            mes "^0000FF[Hangar Mechanic]^000000";
            mes "Mech powered down safely! System diagnostics started.";
        }
        close;
    }

    if (getskilllv("NC_MADOLICENCE") < 1) {
        mes "^0000FF[Hangar Mechanic]^000000";
        mes "Error! You lack Madogear pilot credentials (NC_MADOLICENCE).";
        close;
    }

    mes "^0000FF[Hangar Mechanic]^000000";
    mes "Select active chassis framework index to board:";
    next;

    set .@type, select("Industrial Mech (MADO_ROBOT):Tactical Exosuit (MADO_SUIT)");
    
    if (.@type == 1) {
        setmadogear true, MADO_ROBOT;
    } else {
        setmadogear true, MADO_SUIT;
    }

    mes "^0000FF[Hangar Mechanic]^000000";
    mes "Ignition sequence finalized! All systems operating green.";
    close;
}

      In this script:

      The Hangar Mechanic controls high-tech deployments:

      • We call checkmadogear() on line 11 to check Mech pilot statuses.
      • If boarded, calling setmadogear false on line 15 commands the client engine to dismount systems gracefully.
      • Skill parameters are checked using NC_MADOLICENCE checks on line 22.
      • Once we retrieve their visual choice, we mount the user with either MADO_ROBOT or MADO_SUIT constants on lines 31-35.
