      setlook, changelook

      What are setlook and changelook? 🤔

      The setlook and changelook commands alter the visual look data for a target character. They are mainly used to customize hair styles, palette custom hair/clothing colors, and handle weapon/shield appearances.

      Critical distinction:

      • setlook saves the changes permanently in the character database, remaining active when logging out/in.
      • changelook modifies the presentation client-side only (temporary) and does NOT persist across database reloads, teleports, or relogs.

      Syntax 📜

      • setlook <look type>,<look value>{,<char_id>};
      • changelook <look type>,<look value>{,<char_id>};

      Look Type Constants 🎯

      Below is the complete catalog of valid look types available for utilization:

      Look Type Value / Explanation
      LOOK_BASEBase character sprite.
      LOOK_HAIRActive hairstyle configuration index.
      LOOK_WEAPONEquipped weapon rendering type.
      LOOK_HEAD_BOTTOMBottom position headgear appearance.
      LOOK_HEAD_TOPTop position headgear appearance.
      LOOK_HEAD_MIDMid position headgear appearance.
      LOOK_HAIR_COLORColor pallet mapped hair styling.
      LOOK_CLOTHES_COLORColor pallet mapped clothing dyes.
      LOOK_SHIELDShield visualization index.
      LOOK_SHOESShoes look indexes (kept for compatibility with Gravity Client).
      LOOK_BODY2Advanced body visual styling setup.

      ⚠️ Note: Only look configurations for hairstyle, hair color, and clothing colors are natively stored/reloaded by the rAthena character database tables.

      Examples 💡

      Example 1: Styling Permanent Dye NPC
      //===== rAthena Script =======================================
//= Perfect Hair Dye NPC
//============================================================
prontera,150,150,4	script	Hair Colorist	99,{
    mes "^0000FF[Stylist]^000000";
    mes "Hello! Want to paint your hair blue?";
    next;
    
    if (select("Yes, make me blue!:No thanks") == 2) {
        mes "^0000FF[Stylist]^000000";
        mes "Fine! Come back whenever you wish to upgrade.";
        close;
    }
    
    // Set LOOK_HAIR_COLOR to palette 12 permanently
    setlook LOOK_HAIR_COLOR, 12;
    mes "^0000FF[Stylist]^000000";
    mes "All set! Look at yourself in the mirror!";
    close;
}

      In this script:

      • The command setlook LOOK_HAIR_COLOR, 12 alters the hair color of the invoking player using palette 12 and registers it in the database.
      Example 2: Temporary Costume Disguise
      //===== rAthena Script =======================================
//= Hologram Disguiser
//============================================================
prontera,170,150,4	script	Tech Hologram	99,{
    mes "^0000FF[Hologram]^000000";
    mes "I can temporarily dye your outfit black for local fun.";
    next;
    
    // Apply changelook for LOOK_CLOTHES_COLOR with target palette index 5
    changelook LOOK_CLOTHES_COLOR, 5;
    
    mes "^0000FF[Hologram]^000000";
    mes "You are wearing a temporary disguise! It will reset upon client map re-warp.";
    close;
}

      In this script:

      • The command changelook LOOK_CLOTHES_COLOR, 5 switches the clothing texture presentation of the current slot to dye 5. The change is client-only and resets upon teleport or map change.
