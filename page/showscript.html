      showscript()

      What is showscript? 🤔

      The showscript() command makes an attached player (or specified entity Game ID) shout a text description line directly above their head (similar to shouting a active spell or skill name).

      Crucially, the message prints visually in a balloon popup seen by surrounding active players inside the vicinity, but does **not** register inside their text chat window. This reduces chat spam significantly and creates immersive, high-quality visual alerts.

      Syntax of showscript? 📜

      • showscript("<message>"{,<GID>,<flag>});

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      "<message>" String The literal shouting phrase or announcement to highlight above the character standard boundary.
      <GID> (Optional) Integer / GID The Game ID of the target entity (Player, Monster, or NPC) who should shout the alert. If omitted, defaults to the invoking character player context.
      <flag> (Optional) Constant Identifier Determines who receives/views the shouted lines:
      AREA - Message is sent to players in the vicinity of the source (default).
      SELF - Message is sent only to the player attached to the execution context.

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= Magic Spell Shout System
//= Demonstrates showscript to display bubble announcements
//============================================================
prontera,150,150,4	script	Spells Master	99,{
    mes "^0000FF[Spells Master]^000000";
    mes "Greetings! Do you want me to cast a dummy visual firestorm spell on you?";
    next;
    
    if (select("Cast Firestorm!:No, I am safe") == 2) {
        close;
    }
    
    // Cast progress trigger
    showscript "Level 10 FIRESTORM ACTIVE!", getcharid(3), AREA;
    specialeffect 18; // Red magical circle effect
    
    mes "^0000FF[Spells Master]^000000";
    mes "Cast successfully signaled! Look above your head closely!";
    close;
}

      In this script:

      • The command showscript triggers on line 13 to make the player shout their level 10 spell status.
      • The message displays instantly inside the player's overhead vicinity bubble, while avoiding adding visual clutter to the local chat scroll list.
