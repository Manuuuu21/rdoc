      setmounting(), ismounting()

      What is setmounting and ismounting? 🤔

      The setmounting() command toggles global Cash Shop Mount Board states on a player. The accompanying ismounting() function returns whether the player is currently riding these specialized cash shop boards.

      Unlike standard animal mounts tied to specific job classes (namely PecoPeco, Warg, Dragon, or Madogear), Cash Shop mounts can be boarded by any class character. However, **the command will strictly fail** if the character is currently riding class-specific mounts. It is critical to dismount those class mounts first.

      Syntax Specifications 📜

      • setmounting {<char_id>};
      • ismounting({<char_id>});

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      <char_id> (Optional) Integer The character ID. If supplied, targets that specific player instead of the currently attached one.

      Return Values ↩️

      • setmounting: Returns **1** if the mount toggle was successful, and **0** if blocked or failed.
      • ismounting: Returns **1** if riding a cash shop board mount, and **0** if on foot.

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= Cash Board Rental Depot
//= Demonstrates ismounting() and setmounting() with safety checks
//============================================================
prontera,160,210,4	script	Board Handler	105,{
    mes "^0000FF[Board Handler]^000000";
    mes "Greetings! Ready to board our custom military cash mounts?";
    mes "Our standard models are available to any class of warrior!";
    next;

    if (ismounting()) {
        mes "^0000FF[Board Handler]^000000";
        mes "Active cash board detected. Power off board?";
        next;
        if (select("Power off board:Keep riding") == 1) {
            setmounting; // Toggles cash mount off
            mes "^0000FF[Board Handler]^000000";
            mes "Board powered down successfully! See you around.";
        }
        close;
    }

    // Safety verify: Lacking animal class mounts first
    if (checkriding() || checkdragon() || checkmadogear() || checkwug()) {
        mes "^0000FF[Board Handler]^000000";
        mes "Transit blocked! You must dismount class-specific beasts first.";
        close;
    }

    mes "^0000FF[Board Handler]^000000";
    mes "Assign an experimental board now?";
    next;

    if (select("Ignite Board:Walk away") == 1) {
        if (setmounting()) {
            mes "^0000FF[Board Handler]^000000";
            mes "Board active! Stay safe on the road.";
        } else {
            mes "Error: Deployment rejected. Contact server admin.";
        }
    }
    close;
}

      In this script:

      The Board Handler manages board assignments:

      • On line 11, we call ismounting() to check if they have a cash board equipped.
      • We perform safety reviews on line 22, checking checkriding(), checkdragon(), checkmadogear(), and checkwug() to avoid client side conflicts.
      • Calling setmounting on line 32 triggers the board's deployment and returns status checks dynamically.
