      basicskillcheck()

      What is basicskillcheck? 🤔

      The basicskillcheck() function queries and returns the active status of the configuration setting basic_skill_check inside the map server configuration files (specifically conf/battle/battle_athena.conf or equivalent).

      On classic rAthena setups, the basic_skill_check restriction is enabled by default. This mandates that Novice characters must train and level up their **Basic Skill** (NV_BASIC) to specific thresholds to unlock basic mechanical behaviors (such as sitting, trade requests, using emotes, opening chatrooms, or forming parties). When building tutorials, starter academies, or custom UI dashboards, scripts can check this option to selectively guide users or waive prerequisite prompts dynamically.

      Syntax of basicskillcheck? 📜

      • basicskillcheck()

      Return Values ↩️

      • Returns **1** if basic_skill_check is active and enabled on the server.
      • Returns **0** if disabled, meaning novice characters possess full mechanical privileges from level 1.

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= Novice Academy Instructor
//= Showcases basicskillcheck() to adjust instructions dynamically
//============================================================
new_1-1,53,111,4	script	Academy Guide	104,{
    mes "^0000FF[Academy Guide]^000000";
    mes "Greetings, fresh recruit! I will guide you through your first steps.";
    next;

    // Check if the server requires Basic Skill training
    if (basicskillcheck()) {
        set .@basic_level, getskilllv("NV_BASIC");
        
        if (.@basic_level < 9) {
            mes "^0000FF[Academy Guide]^000000";
            mes "Take note: this server runs under ^FF0000Basic Skill Training rules^000000.";
            mes "You currently have Level " + .@basic_level + " Basic Skill.";
            mes "You must reach **Level 9** to unlock trading, vending, and party systems.";
            mes "Please defeat some training dummies to allocate skill points!";
            close;
        }
    }

    mes "^0000FF[Academy Guide]^000000";
    mes "Splendid! You have full access to our global logistics.";
    mes "Would you like me to transport you to the town square?";
    next;
    
    if (select("Yes, please! : No, I will explore more") == 1) {
        warp "prontera", 156, 191;
    }
    close;
}

      In this script:

      The Academy Guide adjusts recruit instructions according to active server conditions:

      • On line 11, we call basicskillcheck() to evaluate server configurations.
      • If it checks out as active (1), we retrieve the player's actual skill levels with getskilllv("NV_BASIC") on line 12.
      • If they are low (less than Level 9), the NPC outlines exact skill requirements to prevent players from wandering into towns confused about why trading or emoting is locked.
      • If the server configuration has basic_skill_check toggled off (0), the entire block is ignored, ensuring a seamless experience for custom high-rate servers!
