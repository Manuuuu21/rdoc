      changesex()

      What is changesex()? 🤔

      The changesex() command changes the gender of the entire account of the attached character.

      If the account is currently marked Male, it becomes Female; conversely, if currently marked Female, it transitions to Male.

      ⚠️ Behavior warning: Processing this change immediately writes to the login database and character tables, sends the message: "Need disconnection to perform change-sex request...", and forcefully kicks the player back to the login screen so the database modifications can settle.

      Skill Reset Safeguard: Bards, Clowns, Dancers, and Gypsies are gender-locked classes. If there are any characters of these classes anywhere on the account, their skills will be fully reset upon executing this command to prevent invalid skills.

      Syntax of changesex() 📜

      • changesex({<char_id>})

      Example Usage 💡

      Example Code:
      prontera,150,150,4	script	Gender Swapper	99,{
    mes "^0000FF[Gender Swapper]^000000";
    mes "Greetings. Do you want to swap the gender of your login account?";
    mes "You will be disconnected immediately upon accepting.";
    next;
    
    if (select("Yes, change my account gender:No, keep my gender") == 2) {
        mes "^0000FF[Gender Swapper]^000000";
        mes "Understood. The operation was canceled safety.";
        close;
    }
    
    // Execute a complete account-wide gender change
    changesex();
    close;
}

      In this script:

      • On line 12, changesex() writes the SQL update queries, logs the character off, and forces an immediate server disconnect sequence, keeping the database in sync.
