      savepoint, save

      What are savepoint & save? 🤔

      The savepoint and save commands determine the home location of a character player session (the map and coordinates they return to upon using direct save-warping skills, items, logging in, or dying in combat).

      No Exceptions: These commands ignore any active mapflags (such as `nosave`) and can write save points inside zone environments normally inaccessible to standard teleportation mechanisms, making them the classic method to register spawns inside town centres!

      Syntax of savepoint & save? 📜

      • savepoint("<map name>",<x>,<y>{,{<range x>,<range y>,}<char_id>});
      • save("<map name>",<x>,<y>{,{<range x>,<range y>,}<char_id>});

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      "<map name>" String Target map name to register as the player's respawn point.
      <x>, <y> Integer The coordinates where the player will physically spawn upon returning.
      <range x>, <range y> (Optional) Integer Optional scatter offsets. Instantly randomizes the save point by choosing cells between x - range_x and x + range_x and between y - range_y and y + range_y.
      <char_id> (Optional) Integer Specific character ID number whose save state should change. If omitted, defaults to the invoking player.

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= Inn Keeper Save Point Service
//= Demonstrates savepoint to register home coordinates
//============================================================
prontera,150,165,4	script	Prontera Inn Keeper	99,{
    mes "^0000FF[Inn Keeper]^000000";
    mes "Welcome to the Prontera Lounge Inn, traveler.";
    mes "Would you like to register this cozy lobby as your return home point?";
    next;
    
    if (select("Yes, please save me here:No, thank you") == 2) {
        mes "^0000FF[Inn Keeper]^000000";
        mes "Safe travels, adventurer!";
        close;
    }
    
    // Register save point on "prontera" at (150,165) with a scatter of 3 cells
    savepoint "prontera", 150, 165, 3, 3;
    
    mes "^0000FF[Inn Keeper]^000000";
    mes "Success! Your save point has been comfortably locked in.";
    close;
}

      In this script:

      • The command savepoint triggers elegantly on line 15.
      • The target coordinates prontera, 150, 165 are saved securely into the player's session directory database.
      • A randomized grid offset of 3,3 cells ensures that multiple players spawning back to the hotel won't clog or get stuck on the same tile!
