      itemlink()

      What is itemlink? 🤔

      Generates an item link string for an item that can be used for npctalk, message, dispbottom, and broadcast commands. The result is a clickable-item name just like SHIFT+Click from a player's inventory/cart/equipment window. This command can be used with mes but the item name will not be clickable. You should use script command "mesitemlink" for displaying item links in mes dialogues, if the client supports them.

      RandomIDArray, RandomValueArray, and RandomParamArray only works if the client (and server) supports the Item Random Options feature (PACKETVER >= 20150225).

      Syntax of itemlink 📜

      • itemlink(<item_id>{,<refine>{,<card0>{,<card1>{,<card2>{,<card3>,{<enchantgrade>{,<RandomIDArray>,<RandomValueArray>,<RandomParamArray>}}}}}}});

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      <item_id> Integer The database ID of the item from item_db.yml.
      <refine> (Optional) Integer The refine (upgrade) level of the equipment (e.g., 0 to 20).
      <card0> (Optional) Integer Item ID of the card or enchant in slot 1 (or 0 if empty).
      <card1> (Optional) Integer Item ID of the card or enchant in slot 1 (or 0 if empty).
      <card2> (Optional) Integer Item ID of the card or enchant in slot 2 (or 0 if empty).
      <card3> (Optional) Integer Item ID of the card or enchant in slot 3 (or 0 if empty).
      <enchantgrade> (Optional) Integer The enchant grade constant (e.g., ENCHANTGRADE_D .. ENCHANTGRADE_A).
      <RandomIDArray> (Optional) Array An array variable containing Random Option IDs.
      <RandomValueArray> (Optional) Array An array variable containing Random Option values.
      <RandomParamArray> (Optional) Array An array variable containing Random Option parameters.

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= itemlink Demonstration NPC
//= Demonstrates how to use itemlink
//============================================================
prontera,150,150,4	script	ItemlinkDemo	100,{
    mes "[ItemlinkDemo]";
    npctalk "Knife [3] : "+itemlink(1201)+"";
        npctalk "+16 Knife [3] : "+itemlink(1201,16)+"";
        npctalk "+13 BXB Bapho+VR+EA2+EA1 : "+itemlink(18110,13,4147,4407,4833,4832)+"";
        setarray .@opt_ids[0],RDMOPT_VAR_ATKPERCENT,RDMOPT_VAR_ATKPERCENT,RDMOPT_VAR_ATTMPOWER,0,0;
        setarray .@opt_values[0],3,5,20,0,0;
        setarray .@opt_params[0],0,0,0,0,0;
        npctalk "+13 BXB Bapho+VR+EA2+EA1 + 3 Options : "+itemlink(18110,13,4147,4407,4833,4832,0,.@opt_ids,.@opt_values,.@opt_params)+"";
    close;
}

      In this script:

      • The script defines an NPC object on prontera (or the target map) that triggers when a player interacts with it.
      • It invokes itemlink with the required arguments as specified in the rAthena scripting reference.
      • Any resulting state change, return value, or player/unit update is processed immediately within the active script execution context.
