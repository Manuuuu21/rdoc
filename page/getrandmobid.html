      getrandmobid()

      What is getrandmobid? 🤔

      This command returns a random monster ID from the random monster group. With <flag> you can apply certain restrictions which monsters of the group can be returned. Returns 0 if one of the parameters is invalid or no monster could be found with the given parameters.

      - (except those from MOBG_BLOODY_DEAD_BRANCH)

      Syntax of getrandmobid 📜

      • getrandmobid(<type>{,<flag>{,<level>}})

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      <type> Integer The information or operation type constant/index to query or apply.
      <flag> (Optional) Integer Bitmask or mode flag controlling specific behavior of the command (see flag options below).
      <level> (Optional) Integer The target level value.

      Constants & Options ⚙️

      Valid <type> are:

      MOBG_BRANCH_OF_DEAD_TREE MOBG_PORING_BOX MOBG_BLOODY_DEAD_BRANCH MOBG_RED_POUCH_OF_SURPRISE MOBG_CLASSCHANGE MOBG_TAEKWON_MISSION

      Valid <flag> are:

      Constant / Value Description
      RMF_NONE 0x00 - Apply no flags
      RMF_DB_RATE 0x01 - Apply the summon success chance found in the list (otherwise get any monster from the db)
      RMF_CHECK_MOB_LV 0x02 - Apply a monster level check
      RMF_MOB_NOT_BOSS 0x04 - Selected monster should not be a Boss type (default)
      Constant / Value Description
      RMF_MOB_NOT_SPAWN 0x08 - Selected monster must have normal spawn
      RMF_MOB_NOT_PLANT 0x10 - Selected monster should not be a Plant type
      RMF_ALL 0xFF - Apply all flags

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= getrandmobid Demonstration NPC
//= Demonstrates how to use getrandmobid
//============================================================
prontera,150,150,4	script	GetrandmobidDemo	100,{
    mes "^0000FF[GetrandmobidDemo]^000000";
    mes "Testing the getrandmobid command.";
    next;

    .@result = getrandmobid(0);
    mes "Result of getrandmobid: " + .@result;
    close;
}

      In this script:

      • The script defines an NPC object on prontera (or the target map) that triggers when a player interacts with it.
      • It invokes getrandmobid with the required arguments as specified in the rAthena scripting reference.
      • Any resulting state change, return value, or player/unit update is processed immediately within the active script execution context.
