      getusers()

      What is getusers? 🤔

      The getusers() function determines and returns the total number of connected players located either globally across the whole server, locally on the invoking user's map, or on the absolute map coordinate sector containing the running NPC itself.

      Using this function is highly standard for system notifications and informational dashboards that display community metrics, lobby capacity limits, or alert administrators when server traffic climbs or drops.

      Syntax of getusers? 📜

      • getusers(<type>)

      Syntax Parameter Explanation 🧩

      Type Argument Scope Mapped Description
      0 Invoking Character's Map Counts all characters situated on the physical map cell structure currently occupied by the player character initiating the script.
      1 Entire Server (Global) Counts all active connected characters present across all server sectors simultaneously. Excellent for server information boards!
      8 NPC's Map Location Counts all active characters present on the exact physical map that hosts this specific NPC unit, regardless of which player triggered it.

      Return Value ↩️

      • Returns an **integer** representing the player head-count active within the specified scopes.

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= Server Metrics & Sells Agent NPC
//===== By: rAthena AI Assistant ============================
//= Showcases getusers(1) to count all global users online
//============================================================
prontera,160,170,4	script	Imperial Informer	909,{
    // Check global server population
    set .@total_online, getusers(1);

    // Check count on the current physical map
    set .@local_online, getusers(0);

    mes "^0000FF[Imperial Informer]^000000";
    mes "My lord! I keep records of the kingdom's activity daily.";
    mes "There are currently ^00FF00" + .@local_online + "^000000 citizens browsing within this sector.";
    next;

    mes "^0000FF[Imperial Informer]^000000";
    mes "Across the entire kingdom realm, there are:";
    mes "^FF0000" + .@total_online + "^000000 heroes active online.";
    next;

    if (.@total_online >= 100) {
        mes "^0000FF[Imperial Informer]^000000";
        mes "The kingdom is highly bustling and prosperous today! Glorious days!";
    } else {
        mes "^0000FF[Imperial Informer]^000000";
        mes "It is a peaceful, quiet day in the realm.";
    }
    close;
}

      In this script:

      This Imperial Informer dashboard illustrates clean population sampling:

      • The command getusers(1) polls the global login and char server registers securely to extract the complete population count on line 7.
      • The command getusers(0) operates dynamically relative to the triggers, reporting local density specifically. This is perfect for light-weight tracking dashboards.
