      announce

      What is announce? 🤔

      This command will broadcast a message to all or most players, similar to @kami/@kamib GM commands.

      The region the broadcast is heard in (target), source of the broadcast and the color the message will come up as is determined by the flags.

      The flag values are coded as constants in src/map/script_constants.hpp to make them easier to use.

      You cannot use more than one target flag.

      (useful when a player is not attached or the message should be sent to those nearby the NPC). You cannot use more than one source flag.

      Due to the way client handles broadcasts, it is impossible to set both bc_blue and bc_woe.

      The optional parameters allow usage of broadcasts in custom colors, font-weights, sizes etc. If any of the optional parameters is used, special flag is ignored. Optional parameters may not work well (or at all) depending on a game client used.

      The color parameter is a single number which can be in hexadecimal notation. For example:

      Will display a global announce in green. The color format is in RGB (0xRRGGBB).

      In official scripts only two font-weights (types) are used: - normal (FW_NORMAL = 400, default), - bold (FW_BOLD = 700).

      Default font size is 12.

      Using this for private messages to players is probably not that good an idea, but it can be used instead in NPCs to "preview" an announce.

      Syntax of announce 📜

      • announce "<text>",<flag>{,<fontColor>{,<fontType>{,<fontSize>{,<fontAlign>{,<fontY>{,<char_id>}}}}}};

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      "<text>" String The text message to display or broadcast.
      <flag> Integer Bitmask or mode flag controlling specific behavior of the command (see flag options below).
      <fontColor> (Optional) Integer The hex RGB font color value (e.g., 0xFFCC00).
      <fontType> (Optional) Constant / Integer Specifies the <fontType> parameter for announce.
      <fontSize> (Optional) Integer Specifies the <fontSize> parameter for announce.
      <fontAlign> (Optional) Constant / Integer Specifies the <fontAlign> parameter for announce.
      <fontY> (Optional) Integer Specifies the <fontY> parameter for announce.
      <char_id> (Optional) Integer The target character ID. If omitted, defaults to the currently attached player (RID).

      Constants & Options ⚙️

      Target flags:

      Constant / Value Description
      bc_all Broadcast message is sent server-wide (default).
      bc_map Message is sent to everyone in the same map as the source of the broadcast (see below).
      bc_area Message is sent to players in the vicinity of the source.
      bc_self Message is sent only to current player , if the source flag is bc_pc it also can be used to send the Message to the character id if it's provided.

      Source flags:

      Constant / Value Description
      bc_pc Broadcast source is the attached player or the character id if it's provided (default).
      bc_npc Broadcast source is the NPC, not the player attached to the script

      Special flags:

      Constant / Value Description
      bc_yellow Broadcast will be displayed in yellow color (default).
      bc_blue Broadcast will be displayed in blue color.
      bc_woe Indicates that this broadcast is 'WoE Information' that can be disabled client-side.

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= announce Demonstration NPC
//= Demonstrates how to use announce
//============================================================
prontera,150,150,4	script	AnnounceDemo	100,{
    mes "[AnnounceDemo]";
    announce "This will be shown to everyone at all in yellow.",0;
    close;
}

      In this script:

      • The script defines an NPC object on prontera (or the target map) that triggers when a player interacts with it.
      • It invokes announce with the required arguments as specified in the rAthena scripting reference.
      • Any resulting state change, return value, or player/unit update is processed immediately within the active script execution context.
      Example 2:
      //===== rAthena Script =======================================
//= announce Demonstration NPC
//= Demonstrates how to use announce
//============================================================
prontera,150,150,4	script	AnnounceDemo	100,{
    mes "[AnnounceDemo]";
    announce "This will be shown to everyone at all in green.",bc_all,0x00FF00;
    close;
}
      Example 3:
      //===== rAthena Script =======================================
//= announce Demonstration NPC
//= Demonstrates how to use announce
//============================================================
prontera,150,150,4	script	AnnounceDemo	100,{
    mes "[AnnounceDemo]";
    // This will be a private message to the player using the NPC that made the
        // announcement
        announce "This is my message just for you",bc_blue|bc_self;

        // This will be shown on everyones screen that is in sight of the NPC.
        announce "This is my message just for you people here",bc_npc|bc_area;

        // This will be a private message to the player with character id 150000
        announce "This is my message just for char id 150000",bc_self,0xFFF618,FW_NORMAL,12,0,0,150000;
    close;
}
