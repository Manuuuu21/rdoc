      checkweight()

      What is checkweight? 🤔

      The checkweight() suite of functions determines if the invoking player character has enough carrying capacity (unoccupied weight limit) to hold a specified list of items and their quantities.

      It is an absolute best practice in rAthena scripting to invoke checkweight() or checkweight2() before distributing items using getitem. If items are given to an overloaded player, the items may be dropped on the ground or be permanently lost under older server configurations, producing extremely poor user experiences and potential player complaints.

      Syntax of checkweight? 📜

      • checkweight(<item id>, <amount>{, <item id>, <amount>, ...})
      • checkweight("<item name>", <amount>{, "<item name>", <amount>, ...})
      • checkweight2(<id_array>, <amount_array>)

      Syntax Parameter Explanation 🧩

      Signature Variable Types Description
      checkweight(...) Integer / String, Integer Standard mode. Accepts alternating listing of item IDs (or database names) and quantities. Supports checking multiple unique items in a single call.
      checkweight2(...) Integer Array, Integer Array Array mode. Perfect when evaluating a dynamic shopping cart or script rewards stored in arrays. Accepts two arrays of equal size.

      Return Values ↩️

      • Returns **1** if the player can carry the combined weight of all specified items without exceeding their limit.
      • Returns **0** if adding these items would overload the character's inventory space or weight capacities.

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= Secure Item Exchanger & Rewarder
//= Showcases checkweight() and checkweight2()
//============================================================
prontera,165,185,4	script	Supply Clerk	103,{
    mes "^0000FF[Supply Clerk]^000000";
    mes "Hello warrior! I dispense quest packages.";
    mes "Would you like our classic package, or our heavy bulk array?";
    next;

    select("Classic Pack (Apples & Potions)", "Bulk Reward (Array Pack)");
    next;

    if (@menu == 1) {
        // Checking weight for specific items: 10 Apples (ID: 512) and 5 Red Potions (ID: 501)
        if (!checkweight(512, 10, 501, 5)) {
            mes "^0000FF[Supply Clerk]^000000";
            mes "Error! Your bags are too heavy to hold these supplies.";
            close;
        }

        getitem 512, 10;
        getitem 501, 5;
        mes "Classic Pack distributed successfully!";
        close;
    } else {
        // Defining bulk rewards arrays
        setarray .@items[0], 512, 513, 514;   // Apple, Banana, Grape
        setarray .@amounts[0], 50, 50, 50;   // 50 of each

        // Call checkweight2 to safely check the entire list
        if (!checkweight2(.@items, .@amounts)) {
            mes "^0000FF[Supply Clerk]^000000";
            mes "Error! This massive bulk package is too heavy for you.";
            close;
        }

        for (set .@i, 0; .@i < getarraysize(.@items); set .@i, .@i + 1) {
            getitem .@items[.@i], .@amounts[.@i];
        }
        mes "Bulk package distributed securely!";
        close;
    }
}

      In this script:

      The Supply Clerk coordinates safe reward handoffs:

      • On line 14, standard checkweight() performs an aggregate evaluation of 10 Apples and 5 Red Potions against the player's available weight budget.
      • Inside the bulk reward branch on line 30, we declare two separate parallel arrays for items (.@items) and their corresponding stacks (.@amounts).
      • Calling checkweight2(.@items, .@amounts) on line 34 processes the combined list weight in a single optimized engine execution, ensuring standard players never end up stranded with a partial loot claim.
