      setcart(), checkcart()

      What is setcart and checkcart? 🤔

      The setcart() command awards or removes a cargo pushcart from the target player character. The accompanying checkcart() function checks if the player holds a cart of any visual style.

      Ordinarily, characters require the Merchant class passive skill "Pushcart" (MC_PUSHCART) to hold a cart, but utilizing setcart from a script will manually mount the specified style on any class character successfully. Keep in mind that for standard gameplay compatibility, it is best to check class suitability or item requirements beforehand.

      Syntax Specifications 📜

      • setcart {<type>{, <char_id>}};
      • checkcart({<char_id>});

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      <type> Integer The style index of the cart (usually 1 to 5). Specifying 0 completely removes the current pushcart.
      <char_id> (Optional) Integer The character ID. If supplied, targets that specific player instead of the currently attached one.

      Return Values (checkcart) ↩️

      • Returns **1** if the character currently has any style of cart equipped.
      • Returns **0** if they do not possess a cart.

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= Merchant Cart Rental Station
//= Showcases checkcart() and setcart() with style indexes
//============================================================
prontera,160,180,4	script	Cart Rental Agent	100,{
    mes "^0000FF[Cart Agent]^000000";
    mes "Hello merchant! Need some extra mobile space?";
    mes "For a small fee, I can rent you a customized heavy cargo pushcart.";
    next;

    if (checkcart()) {
        mes "^0000FF[Cart Agent]^000000";
        mes "Wait a second, you already have an active cart equipped!";
        next;
        if (select("Keep active cart:Return equipped cart") == 2) {
            setcart 0; // Removes equipped cart
            mes "^0000FF[Cart Agent]^000000";
            mes "Cart returned successfully! See you next time.";
        }
        close;
    }

    // Check MC_PUSHCART skill level
    if (getskilllv("MC_PUSHCART") < 1) {
        mes "^0000FF[Cart Agent]^000000";
        mes "Sorry, you lack Pushcart training (MC_PUSHCART) to handle our gear.";
        close;
    }

    mes "^0000FF[Cart Agent]^000000";
    mes "Choose your desired visual cart design index:";
    next;

    set .@style, select("Classic Wood Cart (Type 1):Iron Reinforced Cart (Type 2):Guild Cargo Cart (Type 3)");
    
    setcart .@style; // Assigns selected cart index
    mes "^0000FF[Cart Agent]^000000";
    mes "Enjoy your heavy Cargo Cart style index: " + .@style + "!";
    close;
}

      In this script:

      The Rental Agent manages player cargo options safely:

      • On line 11, we call checkcart() to see if they already hold a cart.
      • If they do, selecting "Return equipped cart" invokes setcart 0 on line 15 to remove the cart dynamically.
      • We call getskilllv("MC_PUSHCART") on line 22 to verify class capability.
      • If compliant, we read the selected style and execute setcart .@style on line 31 to equip the new model instantly.
