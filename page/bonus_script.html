      bonus_script

      What is bonus_script? 🤔

      This command will attach a script to a player for a given duration, in seconds. After that time, the script will automatically expire. The same bonus cannot be stacked. By default, this bonus will be stored on "bonus_script" table when player logs out.

      if both are defined, 1024 will be checked first and ignore this flag.

      Types: This will be used to decide negative or positive buff for debuff_on_logout.

      Status_icon: See "Status Icon" section in src/map/script_constants.hpp. Default is SI_BLANK (-1).

      Syntax of bonus_script 📜

      • bonus_script "<script code>",<duration>{,<flag>{,<type>{,<status_icon>{,<char_id>}}}};

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      "<script code>" String Specifies the <script code> parameter for bonus_script.
      <duration> Integer Duration of the effect or state in milliseconds (or seconds depending on command).
      <flag> (Optional) Integer Bitmask or mode flag controlling specific behavior of the command (see flag options below).
      <type> (Optional) Integer The information or operation type constant/index to query or apply.
      <status_icon> (Optional) Constant / Integer Specifies the <status_icon> parameter for bonus_script.
      <char_id> (Optional) Integer The target character ID. If omitted, defaults to the currently attached player (RID).

      Constants & Options ⚙️

      Flags (bitmask):

      Constant / Value Description
      1 Remove when dead.
      2 Removable by Dispell.
      4 Removable by Clearance.
      8 Remove when player logs out.
      16 Removeable by Banishing Buster.
      32 Removable by Refresh.
      64 Removable by Lux Anima.
      128 Remove when Madogear is activated or deactivated.
      256 Remove when receive damage.
      512 Script is permanent, cannot be cleared by bonus_script_clear.
      1024 Force to replace duplicated script by expanding the duration.
      2048 Force to add duplicated script. This flag cannot be stacked with 1024,
      Constant / Value Description
      0 Ignore the buff type and won't be removed if the flag is not &8 (Default)
      1 Buff
      2 Debuff

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= bonus_script Demonstration NPC
//= Demonstrates how to use bonus_script
//============================================================
prontera,150,150,4	script	BonusScriptDemo	100,{
    mes "[BonusScriptDemo]";
    - Id: 512
        AegisName: Apple
        Name: Apple
        Type: Healing
        Buy: 15
        Weight: 20
        Flags:
          BuyingStore: true
        Script: |
          bonus_script "{ bonus bStr,5; }",60;
    close;
}

      In this script:

      • The script defines an NPC object on prontera (or the target map) that triggers when a player interacts with it.
      • It invokes bonus_script with the required arguments as specified in the rAthena scripting reference.
      • Any resulting state change, return value, or player/unit update is processed immediately within the active script execution context.
