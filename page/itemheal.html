      itemheal()

      What is itemheal? 🤔

      The itemheal command restores relative amount of HP and/or SP on the invoking character.

      Unlike its sister command heal, itemheal is explicitly engineered for **use in item databases / scripts**. It dynamically incorporates potion-related modifier factors such as the user's Vitality (VIT) or Intelligence (INT) values, card multipliers, ranking bonuses (e.g. Alchemist ranked potion lists), and status changes (e.g. medical boosts).

      Calculations 🔍

      heal_total = base_heal * [(100 + STATUS_STAT * 2) / 100]

      For instance, if a character has 50 Vitality and consumes an item containing 100 base healing, the multiplier applies: (100 + (50 * 2)) / 100 = 2.0x, resulting in an output of exactly 200 HP healed safely.

      Syntax of itemheal? 📜

      • itemheal <hp>,<sp>{,<char_id>};

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      <hp> Integer / Formula The base HP value to recover. Supports random ranges using rand().
      <sp> Integer / Formula The base SP value to recover.
      <char_id> (Optional) Integer Character database ID who consumes the item. Defaults to the active player thread if omitted.

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= Custom Red Potion database record script block
//= Showcases itemheal behavior inside database configurations
//============================================================
// Item Database entry representation:
// {
//     Id: 501
//     AegisName: "Red_Potion"
//     Name: "Red Potion"
//     Type: "Heal"
//     Script: <"
//         // Restores random base HP between 100-150 and exactly 5 SP
//         itemheal rand(100,150), 5;
//         specialeffect 15;
//     ">
// }

      In this script:

      • The command itemheal is defined directly inside database script braces for the standard item Red_Potion.
      • Using itemheal rand(100,150), 5 applies a base restore value. The engine subsequently reads the player's status gear, status buffs, and VIT variables to determine the final inflated healing volume.
