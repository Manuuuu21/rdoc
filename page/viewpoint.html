      viewpoint

      What is viewpoint? 🤔

      This command will mark places on the mini map in the client connected to the invoking character. It uses the normal X and Y coordinates from the main map. The colors of the marks are defined using a hexadecimal number, same as the ones used to color text in mes output, but are written as hexadecimal numbers in C. (They look like 0x<six numbers>.)

      Action is what you want to do with a point, 1 will set it, while 2 will clear it. 0 will also set it, but automatically removes the point after 15 seconds. Point number is the number of the point - you can have several. If more than one point is drawn at the same coordinates, they will cycle, which can be used to create flashing marks.

      Syntax of viewpoint 📜

      • viewpoint <action>,<x>,<y>,<point number>,<color>{,<Char ID>};

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      <action> Constant / Integer Specifies the <action> parameter for viewpoint.
      <x> Integer The X coordinate on the map.
      <y> Integer The Y coordinate on the map.
      <point number> Integer Specifies the <point number> parameter for viewpoint.
      <color> Integer / String The RGB hex color code (e.g., 0xFF0000 or "0xFF0000").
      <Char ID> (Optional) Integer The target character ID. If omitted, defaults to the currently attached player (RID).

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= viewpoint Demonstration NPC
//= Demonstrates how to use viewpoint
//============================================================
prontera,150,150,4	script	ViewpointDemo	100,{
    mes "[ViewpointDemo]";
    // This command will show a mark at coordinates X 30 Y 40, is mark number 1,
        // and will be red.

        viewpoint 1,30,40,1,0xFF0000;
    close;
}

      In this script:

      • The script defines an NPC object on prontera (or the target map) that triggers when a player interacts with it.
      • It invokes viewpoint with the required arguments as specified in the rAthena scripting reference.
      • Any resulting state change, return value, or player/unit update is processed immediately within the active script execution context.
      Example 2:
      //===== rAthena Script =======================================
//= viewpoint Demonstration NPC
//= Demonstrates how to use viewpoint
//============================================================
prontera,150,150,4	script	ViewpointDemo	100,{
    mes "[ViewpointDemo]";
    viewpoint 1,30,40,1,0xFF0000;
        viewpoint 1,35,45,2,0xFF0000;
        viewpoint 1,40,50,3,0xFF0000;
    close;
}
