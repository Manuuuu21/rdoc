      areawarp()

      What is areawarp? 🤔

      The areawarp() command allows warping a group of players within a rectangular coordinate area on a source map over to a specified target map destination.

      No RID Required: Since this command selects players purely based on their spatial location inside world boundaries (coordinates (x1,y1) to (x2,y2)), it does not require an active attached player thread. It can be safely executed from timed triggers, floating scripts, or area events!

      Syntax of areawarp? 📜

      • areawarp("<from map name>",<x1>,<y1>,<x2>,<y2>,"<to map name>",<x3>,<y3>{,<x4>,<y4>});

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      "<from map name>" String The name of the source map where players are located.
      <x1>, <y1>, <x2>, <y2> Integer The coordinate bounds defining the rectangular source selection area on the source map.
      "<to map name>" String The name of the destination map to move the selected players to. Special names such as "Random", "Save", or "SavePoint" are supported.
      <x3>, <y3> Integer The target coordinate coordinates on the target map. Setting these to 0,0 teleports players to random coordinates.
      <x4>, <y4> (Optional) Integer If provided, defines the diagonal opposite corner of a destination box on the target map. Players are teleported randomly inside the box defined by (x3,y3) to (x4,y4).

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= Coliseum Evacuation Lever
//= Evacuates gladiators in area (10,10) to (80,80) on trigger
//============================================================
prontera,160,150,4	script	Evacuation Lever	99,{
    mes "^0000FF[Evacuation Controller]^000000";
    mes "Are you sure you want to pull the emergency lever?";
    mes "This will instantly warp everyone in the central combat area to safety!";
    next;
    
    if (select("Pull Lever!:Cancel") == 2) {
        close;
    }
    
    // Warp all players from arena "bossnia_01" within (20,20) and (180,180)
    // Destination: "prontera" within a random coordinate range of (140,140) to (160,160)
    areawarp "bossnia_01", 20, 20, 180, 180, "prontera", 140, 140, 160, 160;
    
    mes "^0000FF[Evacuation Controller]^000000";
    mes "Emergency evacuation completed successfully!";
    close;
}

      In this script:

      • The command areawarp is invoked safely when pulling the emergency trigger on line 14.
      • All characters situated inside coordinates (20,20) to (180,180) on the bossnia_01 map are selected.
      • Matched entities are randomly scattered on the target map prontera inside coordinates (140,140) to (160,160).
