      progressbar

      What is progressbar? 🤔

      This command works almost like sleep2, but displays a progress bar above the head of the currently attached character (like cast bar). Once the given amount of seconds passes, the script resumes. If the character moves while the progress bar progresses, it is aborted and the script ends. The color format is in RGB (RRGGBB). The color is currently ignored by the client and appears always green.

      Note: NOTE: Ragexe clients are known to randomly crash if a message window is still open. If possible make sure to close all message windows before triggering the progressbar command.

      Syntax of progressbar 📜

      • progressbar "<color>",<seconds>;

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      "<color>" Integer / String The RGB hex color code (e.g., 0xFF0000 or "0xFF0000").
      <seconds> Integer Time duration in seconds.

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= progressbar Demonstration NPC
//= Demonstrates how to use progressbar
//============================================================
prontera,150,150,4	script	ProgressbarDemo	100,{
    mes "^0000FF[ProgressbarDemo]^000000";
    mes "Testing the progressbar command.";
    next;

    progressbar "0x00FF00", 60;
    mes "Executed progressbar successfully!";
    close;
}

      In this script:

      • The script defines an NPC object on prontera (or the target map) that triggers when a player interacts with it.
      • It invokes progressbar with the required arguments as specified in the rAthena scripting reference.
      • Any resulting state change, return value, or player/unit update is processed immediately within the active script execution context.
