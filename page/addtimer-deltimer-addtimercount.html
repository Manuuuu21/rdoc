      addtimer, deltimer, addtimercount

      What are Timer Commands? 🤔

      The timer commands allow scripts to create, manage, and manipulate player-attached countdown timers. They are crucial for implementing delayed quest responses, timed puzzle events, or automatic system cleanups.

      • addtimer initializes a countdown timer referencing a specific event label.
      • deltimer immediately cancels and deletes a running timer.
      • addtimercount adds or delays the countdown timer by the specified number of ticks.

      Important Warning: These timers are stored directly on player character data. If the player logs out, all of these timers are immediately deleted without executing the script! If you want persistent timers, consider alternative timer options like sleep or NPC timers.

      Syntax of Timer Commands 📜

      • addtimer <ticks>,"<NPC name>::<event label>";
      • deltimer "<NPC name>::<event label>";
      • addtimercount <ticks>,"<NPC name>::<event label>";

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      <ticks> Integer The duration or change time specified in milliseconds (1/1000ths of a second). For instance, 5000 represents exactly 5 seconds.
      "<NPC name>::<event label>" String The target NPC object name and event label destination to trigger or update (e.g. "MyNPC::OnFiveSeconds"). You can use strnpcinfo(3) to retrieve the current NPC's name dynamically.

      Example Usage 💡

      Example Code:
      //=====	rAthena Script	=======================================
//=	Coliseum Speed Trial Administrator
//=	Uses addtimer, deltimer and addtimercount to control trials
//============================================================
prontera,150,150,4	script	Trial Master	99,{
    mes "^0000FF[Trial Master]^000000";
    mes "Greetings! Welcome to the Speed Trial Challenge!";
    mes "You will have exactly 10 seconds to finish your trial.";
    next;

    if (select("Start Trial!:Cancel") == 2) {
        close;
    }

    mes "^0000FF[Trial Master]^000000";
    mes "Trial started! The timer begins now!";
    close2;

    // Start a 10-second (10000ms) timer targeting the OnTimeout label
    addtimer 10000, strnpcinfo(3) + "::OnTimeout";
    end;

OnTimeout:
    announce "Trial Master: Time's up! You failed the speed trial.", bc_self;
    end;

OnFinishTrial:
    // If player finishes before timeout, cancel the countdown timer
    deltimer strnpcinfo(3) + "::OnTimeout";
    announce "Trial Master: Congratulations! You completed the speed trial successfully.", bc_self;
    end;

OnAddPenalty:
    // Extend or delay the timeout by adding 5 seconds of penalty time
    addtimercount 5000, strnpcinfo(3) + "::OnTimeout";
    dispbottom "Penalty added! Timer delayed by 5 seconds.";
    end;
}

      In this script:

      • The Coliseum speed trial begins when the user triggers the lever, invoking addtimer 10000 to register a 10-second countdown on line 19.
      • If the 10 seconds elapse, player control immediately jumps to the OnTimeout event on line 22, printing a defeat banner.
      • If the gladiator finishes successfully, we call deltimer on line 27, deleting the active timer cleanly to prevent timeout triggers.
      • If the player breaks rules or hits traps, we invoke addtimercount 5000 on line 32 to add a 5-second penalty buffer (delaying the expiration target dynamically).
