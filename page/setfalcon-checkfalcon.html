      setfalcon(), checkfalcon()

      What is setfalcon and checkfalcon? 🤔

      The setfalcon() command attaches or removes a flying Hunter companion Falcon on the player. The accompanying checkfalcon() function determines if the character possesses a Falcon currently.

      Ordinarily, the character must belong to the Hunter class line and possess the passive skill "Falconry" (HT_FALCON), though assigning it via script coordinates the visual sprite on any character. Note that non-hunter classes will generally gain no gameplay benefits or active attack attributes from Falconry, serving primarily a visual purpose.

      Syntax Specifications 📜

      • setfalcon {<flag>{, <char_id>}};
      • checkfalcon({<char_id>});

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      <flag> Integer Toggle state: Use 1 to attach a Falcon; use 0 to detach/remove.
      <char_id> (Optional) Integer The character ID. If supplied, targets that specific player instead of the currently attached one.

      Return Values (checkfalcon) ↩️

      • Returns **1** if the character currently holds a Falcon.
      • Returns **0** if they do not possess a Falcon.

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= Falconry Training Master
//= Showcases checkfalcon() and setfalcon() with prerequisites
//============================================================
payon,145,160,4	script	Falconry Master	101,{
    mes "^0000FF[Falconry Master]^000000";
    mes "Greetings Archer! Let me inspect your companion status.";
    next;

    if (checkfalcon()) {
        mes "^0000FF[Falconry Master]^000000";
        mes "A beautiful beast circles standard above your head already!";
        next;
        if (select("Keep companion:Return Falcon to cage") == 2) {
            setfalcon 0; // Detach falcon
            mes "^0000FF[Falconry Master]^000000";
            mes "The falcon flies back to its cage. Safe travels!";
        }
        close;
    }

    // Verify Falconry mastery (HT_FALCON)
    if (getskilllv("HT_FALCON") < 1) {
        mes "^0000FF[Falconry Master]^000000";
        mes "Error! You lack falconry comprehension (HT_FALCON). Class locked!";
        close;
    }

    mes "^0000FF[Falconry Master]^000000";
    mes "Whistle for a companion falcon?";
    next;
    
    if (select("Yes, summon!:No, thank you") == 1) {
        setfalcon 1; // Attach falcon mount
        mes "^0000FF[Falconry Master]^000000";
        mes "High-flying auxiliary units summoned. Keep your focus!";
    }
    close;
}

      In this script:

      The Falconry master coordinates player-companion bindings:

      • On line 11, the script calls checkfalcon() to verify companion status.
      • If equipped, calling setfalcon 0 on line 15 clears the falcon visual.
      • We evaluate the requisite passive skill HT_FALCON using getskilllv on line 22.
      • Conforming Archers finally whistle and invoke setfalcon 1 on line 31 to trigger the companion client rendering sequence.
