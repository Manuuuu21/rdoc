      countitem, countitem2, countitem3, countitem4

      What are countitem, countitem2, countitem3, countitem4? 🤔

      This function will return the number of items for the specified item ID that the invoking character has in the inventory.

      Like getitem, this function will also accept an 'english name' from the database as an argument.

      If you want to state the number at the end of a sentence, you can do it by adding up strings:

      Expanded version of countitem function, used for created/carded/forged items.

      This function will return the number of items for the specified item ID and other parameters that the invoking character has in the inventory. See getitem2 for an explanation of the expanded parameters.

      countitem3 is advance version of countitem2 that also use Item Random Option as criteria. <RandomIDArray> : Array variable of ID for item random option, see db/[pre-]re/item_randomopt_db.yml <RandomValueArray> : Array variable of item random option's value. <RandomParamArray> : Array variable of item random option's param.

      countitem4 is advance version of countitem3 that also use the grade as criteria.

      Syntax of countitem, countitem2, countitem3, countitem4 📜

      • countitem(<item id>{,<accountID>})
      • countitem("<item name>"{,<accountID>})
      • countitem2(<item id>,<identify>,<refine>,<attribute>,<card1>,<card2>,<card3>,<card4>{,<accountID>})
      • countitem2("<item name>",<identify>,<refine>,<attribute>,<card1>,<card2>,<card3>,<card4>{,<accountID>})
      • countitem3(<item id>,<identify>,<refine>,<attribute>,<card1>,<card2>,<card3>,<card4>,<RandomIDArray>,<RandomValueArray>,<RandomParamArray>{,<accountID>})
      • countitem3("<item name>",<identify>,<refine>,<attribute>,<card1>,<card2>,<card3>,<card4>,<RandomIDArray>,<RandomValueArray>,<RandomParamArray>{,<accountID>})
      • countitem4(<item id>,<identify>,<refine>,<attribute>,<card1>,<card2>,<card3>,<card4>,<grade>,<RandomIDArray>,<RandomValueArray>,<RandomParamArray>{,<accountID>})
      • countitem4("<item name>",<identify>,<refine>,<attribute>,<card1>,<card2>,<card3>,<card4>,<grade>,<RandomIDArray>,<RandomValueArray>,<RandomParamArray>{,<accountID>})

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      <item id> Integer The database ID of the item from item_db.yml.
      <accountID> (Optional) Integer The target account ID (AID). If omitted, defaults to the currently attached player.
      "<item name>" String The English or Aegis name of the item from item_db.yml.
      <identify> Integer Identification state: 1 = identified, 0 = unidentified.
      <refine> Integer The refine (upgrade) level of the equipment (e.g., 0 to 20).
      <attribute> Integer Equipment broken state: 0 = normal (not broken), 1 = broken.
      <card1> Integer Item ID of the card or enchant in slot 1 (or 0 if empty).
      <card2> Integer Item ID of the card or enchant in slot 2 (or 0 if empty).
      <card3> Integer Item ID of the card or enchant in slot 3 (or 0 if empty).
      <card4> Integer Item ID of the card or enchant in slot 4 (or 0 if empty).
      <RandomIDArray> Array An array variable containing Random Option IDs.
      <RandomValueArray> Array An array variable containing Random Option values.
      <RandomParamArray> Array An array variable containing Random Option parameters.
      <grade> Integer The enchant grade constant (e.g., ENCHANTGRADE_NONE, ENCHANTGRADE_D .. ENCHANTGRADE_A).

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= countitem, countitem2, countitem3, countitem4 Demonstration NPC
//= Demonstrates how to use countitem, countitem2, countitem3, countitem4
//============================================================
prontera,150,150,4	script	CountitemDemo	100,{
    mes "[CountitemDemo]";
    mes "[Item Checker]";
        mes "Hmmm, it seems you have " + countitem(502) + " apples";
        close;
}

      In this script:

      • The script defines an NPC object on prontera (or the target map) that triggers when a player interacts with it.
      • It invokes countitem with the required arguments as specified in the rAthena scripting reference.
      • Any resulting state change, return value, or player/unit update is processed immediately within the active script execution context.
      Example 2:
      //===== rAthena Script =======================================
//= countitem, countitem2, countitem3, countitem4 Demonstration NPC
//= Demonstrates how to use countitem, countitem2, countitem3, countitem4
//============================================================
prontera,150,150,4	script	CountitemDemo	100,{
    mes "[CountitemDemo]";
    mes "[Item Checker]";
        mes "Hmmm, the total number of apples you are holding is " + countitem("APPLE");
        close;
}
