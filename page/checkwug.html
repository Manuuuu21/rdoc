      checkwug()

      What is checkwug? 🤔

      The checkwug() function checks if the target Ranger character is accompanied by their loyal Warg (wolf companion).

      Wargs are specialized companions exclusive to the **Ranger third-job class line**. Script authors query checkwug() in town hubs, custom instanced dungeons, or board rental portals to confirm if a player is riding or using their beast, enabling proper restrictions inside narrow maps or safe-zones.

      Syntax of checkwug? 📜

      • checkwug({<char_id>})

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      <char_id> (Optional) Integer The character ID. If supplied, targets that specific player instead of the currently attached one.

      Return Values ↩️

      • Returns **1** if the Ranger currently has an active Warg companion.
      • Returns **0** if they do not possess a Warg (for example, if they have not summoned it, or belong to different job lines).

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= Ranger Association Lodge Restriction
//= Showcases checkwug() to verify companion status
//============================================================
ra_temple,110,85,4	script	Lodge Ranger Instructor	106,{
    mes "^0000FF[Langer Instructor]^000000";
    mes "Greetings recruit! Standard rules mandate safety inside the temple rooms.";
    mes "Let me check if your Warg is currently loose.";
    next;

    if (checkwug()) {
        mes "^0000FF[Langer Instructor]^000000";
        mes "Active Warg detected! Please return your wolf to its flute container.";
        mes "You must secure your beast before exploring our barracks.";
        close;
    }

    mes "^0000FF[Langer Instructor]^000000";
    mes "All status conditions clear! Clean safety match verified.";
    mes "Would you like to enter the secure hunting training fields?";
    next;
    
    if (select("Yes, please!:No, I will wait") == 1) {
        warp "ra_fild01", 150, 150;
    }
    close;
}

      In this script:

      The Temple Instructor enforces wolf-containment protocols:

      • On line 11, the script invokes checkwug() to detect summoned Rangers beasts.
      • If it checks out as active (1), the entry dialog terminates, preventing loose wolves from wandering the indoor maps.
      • If the user has no active summoned Warg (0), the security checks match perfectly, and portals to field warping are safely unlocked.
