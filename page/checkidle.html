      checkidle()

      What is checkidle? 🤔

      The checkidle() function returns the time, in seconds, that a specified player has been inactive or AFK (idle). This is useful for auditing active participation, identifying inactive automated players, or managing automated event kicks.

      rAthena also includes specialized variants: checkidlehom() and checkidlemer() which are evaluating idle times for Homunculus and Mercenary sharing options respectively.

      Syntax of checkidle? 📜

      • checkidle({"<Player Name>"})
      • checkidlehom({"<Player Name>"})
      • checkidlemer({"<Player Name>"})

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      "<Player Name>" (Optional) String / Character Name The name of the target player. If omitted, defaults to evaluating the currently attached player character (the RID).

      Return Values ↩️

      Returns an integer representing the duration of idleness in seconds.

      Value Returned Meaning
      0The player is actively inputting or has just pressed keys/moved.
      XThe player has been completely idle (no commands or movement) for exactly X seconds.

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= AFK Event Administrator & Idle Checker
//= Checks if a player has been idle for more than 5 minutes
//============================================================
prontera,150,150,4	script	AFK Auditor	100,{
    mes "^0000FF[AFK Auditor]^000000";
    mes "Greetings! Let me inspect your active status.";
    next;

    set .@idle_time, checkidle();

    if (.@idle_time > 300) {
        mes "^0000FF[AFK Auditor]^000000";
        mes "Wow, you have been inactive for " + .@idle_time + " seconds!";
        mes "That is over 5 minutes. Please wake up!";
    } else {
        mes "^0000FF[AFK Auditor]^000000";
        mes "Excellent! You are active. Idle time: " + .@idle_time + " seconds.";
    }
    close;
}

      In this script:

      The auditor checks characters' idle time precisely:

      • The command checkidle() returns the seconds the player was inactive on line 10.
      • If the returned seconds are greater than 300 (5 minutes) on line 12, the auditor flags the player as AFK.
