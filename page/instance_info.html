      instance_info()

      What is instance_info? 🤔

      Returns the specified <info type> of the given <instance name> from the instance database. If the <instance name> is unknown or an invalid <info type> is supplied -1 will be returned.

      Syntax of instance_info 📜

      • instance_info("<instance name>",<info type>{,<instance_db map index>});

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      "<instance name>" String the <instance name> is unknown or an invalid <info type> is supplied -1 will be returned.
      <info type> Integer <info type> is supplied -1 will be returned.
      <instance_db map index> (Optional) String Specifies the <instance_db map index> parameter for instance_info.

      Constants & Options ⚙️

      Valid info types:

      Constant / Value Description
      IIT_ID Instance database ID as integer.
      IIT_TIME_LIMIT Instance database total life time as integer.
      IIT_IDLE_TIMEOUT Instance database timeout time as integer.
      IIT_ENTER_MAP Instance database enter map as string.
      IIT_ENTER_X Instance database enter X location as integer.
      IIT_ENTER_Y Instance database enter Y location as integer.
      IIT_MAPCOUNT Instance database total maps as integer.
      IIT_MAP Instance database map name from the given <instance_db map index> as string. If the index is invalid an empty string will be returned.

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= instance_info Demonstration NPC
//= Demonstrates how to use instance_info
//============================================================
prontera,150,150,4	script	InstanceInfoDemo	100,{
    mes "[InstanceInfoDemo]";
    .@name$ = "Endless Tower";
    mes .@name$ + " will be destroyed if no one is in the instance for " + instance_info(.@name$,IIT_IDLETIMEOUT) + " seconds.";
    // Endless Tower will be destroyed if no one is in the instance for 300 seconds.
    close;
}

      In this script:

      • The script defines an NPC object on prontera (or the target map) that triggers when a player interacts with it.
      • It invokes instance_info with the required arguments as specified in the rAthena scripting reference.
      • Any resulting state change, return value, or player/unit update is processed immediately within the active script execution context.
