      isequipped()

      What is isequipped? 🤔

      The isequipped() function verifies whether the invoking character has specified item or card IDs currently equipped.

      If items are equipment types, it evaluates if they are actively worn. If card IDs are supplied, it checks if they are slotted in any worn equipment. There is theoretically no limit to the number of IDs you can test simultaneously.

      Its sister command isequippedcnt() operates similarly, but instead of returning 1 or 0, it tells you the exact count of items/cards worn from the checked list. This is extremely useful for item set bonuses!

      Syntax 📜

      • isequipped(<item_id>{,<item_id>{,..}})
      • isequippedcnt(<item_id>{,<item_id>{,..}})

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      <item_id> Integer The unique database ID of the equipment, weapon, accessory, or card to check. Multiple items can be passed separated by commas.

      Return Values ↩️

      Command Returns Condition
      isequipped() 1 The invoking character is wearing all listed items/cards.
      isequipped() 0 Even one item from the given parameters is missing or unequipped.
      isequippedcnt() Count (integer) Returns the total number of matches of specified items currently configured and equipped.

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= Card Master Achievement Verifier
//= Uses isequipped() and isequippedcnt() to check cards
//============================================================
prontera,160,150,4	script	Card Collector	105,{
    mes "^0000FF[Card Collector]^000000";
    mes "Let me check if you have qualified for the Poring Fanatic title.";
    next;

    // Check if user has all 4 Poring family cards equipped
    // (Poring Card: 4001, Santa Poring Card: 4005, Poporing Card: 4033, Marin Card: 4196)
    if (isequipped(4001, 4005, 4033, 4196)) {
        mes "^0000FF[Card Collector]^000000";
        mes "Unbelievable! You are wearing all four essential Poring-type Cards!";
        mes "I grant you the Poring Overlord rank!";
    } else {
        set .@cnt, isequippedcnt(4001, 4005, 4033, 4196);
        mes "^0000FF[Card Collector]^000000";
        mes "You have only " + .@cnt + " of 4 Poring cards slotted into your active gear.";
        mes "Keep exploring the lands to find the rest!";
    }
    close;
}

      In this script:

      The Card Collector evaluates slotted card entities:

      • The statement isequipped(4001, 4005, 4033, 4196) on line 12 tests if all four cards are inserted into active slots together.
      • If the match fails, isequippedcnt(4001, 4005, 4033, 4196) counts how many matches are active on line 16, allowing logical gradation of set rewards.
