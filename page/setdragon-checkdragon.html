      setdragon(), checkdragon()

      What is setdragon and checkdragon? 🤔

      The setdragon() command assigns or clears dragon mounts from the invoking character, with specific color support. The companion checkdragon() function returns whether they are currently riding a Dragon.

      Usage of setdragon is tightly guarded by the script engine. The targeted character must strictly belong to the **Rune Knight class line** and must possess the passive skill "Dragon Training" (RK_DRAGONTRAINING) in their skill manifest, or else the command will fail and return 0.

      Syntax Specifications 📜

      • setdragon {<color>{, <char_id>}};
      • checkdragon({<char_id>});

      Available Dragon Colors 🎨

      Color Number Dragon Appearance
      1Green Dragon (default)
      2Brown Dragon
      3Gray Dragon
      4Blue Dragon
      5Red Dragon

      Return Values ↩️

      • setdragon: Returns **1** if successful, and **0** if failed (e.g. invalid class or lacking training skills).
      • checkdragon: Returns **1** if riding a dragon, and **0** otherwise.

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= Runeburg Dragon Stable Coordinator
//= Showcases checkdragon() and setdragon() with color options
//============================================================
prontera,165,195,4	script	Dragon Stable Warden	103,{
    mes "^0000FF[Stable Warden]^000000";
    mes "Greetings Lord Knight! Ready to saddle our dragons?";
    next;

    if (checkdragon()) {
        mes "^0000FF[Stable Warden]^000000";
        mes "You have a massive dragon deployed already. Dismount?";
        next;
        if (select("Dismount safely:Keep writing") == 1) {
            setdragon 0; // Dismount dragon
            mes "^0000FF[Stable Warden]^000000";
            mes "Your dragon walks back into its cell.";
        }
        close;
    }

    if (getskilllv("RK_DRAGONTRAINING") < 1) {
        mes "^0000FF[Stable Warden]^000000";
        mes "You lack Dragon Training mastery (RK_DRAGONTRAINING) to tame beasts.";
        close;
    }

    mes "^0000FF[Stable Warden]^000000";
    mes "Select your desired military dragon color class:";
    next;

    set .@color, select("Green Crested (Type 1):Sand Brown (Type 2):Obsidian Gray (Type 3):Sapphire Blue (Type 4):Crimson Red (Type 5)");
    
    // Attempt dragon mount sequence
    if (setdragon(.@color)) {
        mes "^0000FF[Stable Warden]^000000";
        mes "Taming successful! Ride tall on your colored companion.";
    } else {
        mes "^0000FF[Stable Warden]^000000";
        mes "Critical error: Dragon taming rejected. Check class constraints.";
    }
    close;
}

      In this script:

      The Warden handles elite mounts safely:

      • On line 11, we call checkdragon() to avoid taming duplicates.
      • If checked as active, calling setdragon 0 dismounts the dragon safely.
      • We evaluate the requisite Third-class Knight skill RK_DRAGONTRAINING on line 22.
      • We prompt for a color choice and verify success directly, as shown in the setdragon(.@color) logic on line 32.
