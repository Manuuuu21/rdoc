      getequipid()

      What is getequipid? 🤔

      The getequipid() function in rAthena scripting is used to obtain the Item ID (item_id) of the equipment currently worn by the player in a specific equipment slot. If no item is equipped in the specified slot, the function returns -1.

      Purpose of getequipid? 🎯

      This function is essential for creating NPCs or scripts that scan the player's current gear. Common applications include:

      • Equipment Refiners: Identifying exactly which shield or weapon is currently held in order to safely upgrade it.
      • Item Requirement Checks: Checking if a player has a specific set item or gear equipped before triggering a custom quest event or granting passage into a zone.
      • Card and Option Checkers: Combining this with index functions to look into equipped item cards, slots, or custom weapon properties.
      • Transmutation or Trade NPCs: Consuming or swapping and visual-checking the active item in a specific slot.

      Syntax of getequipid? 📜

      • getequipid({<equipment slot>{,<char_id>}})

      This function returns the item ID of the item slot that calls the script on the invoking character or the specified equipment slot. If nothing is equipped there, it returns -1.

      Equipment Slot Constants 🧩

      Below is the official list of valid equipment slot constants (and their respective numerical values) as defined in the rAthena source code:

      Constant Value Equipment Type / Location
      EQI_COMPOUND_ON -1 Item slot that calls this script (In context of item script) - exclusive to getequipid
      EQI_ACC_L 0 Accessory 1 (Left)
      EQI_ACC_R 1 Accessory 2 (Right)
      EQI_SHOES 2 Footgear (shoes, boots)
      EQI_GARMENT 3 Garment (mufflers, hoods, manteaux)
      EQI_HEAD_LOW 4 Lower Headgear (beards, some masks)
      EQI_HEAD_MID 5 Middle Headgear (masks, glasses)
      EQI_HEAD_TOP 6 Upper Headgear
      EQI_ARMOR 7 Armor (jackets, robes)
      EQI_HAND_L 8 Left hand (weapons, shields)
      EQI_HAND_R 9 Right hand (weapons)
      EQI_COSTUME_HEAD_TOP 10 Upper Costume Headgear
      EQI_COSTUME_HEAD_MID 11 Middle Costume Headgear
      EQI_COSTUME_HEAD_LOW 12 Lower Costume Headgear
      EQI_COSTUME_GARMENT 13 Costume Garment
      EQI_AMMO 14 Arrow/Ammunition
      EQI_SHADOW_ARMOR 15 Shadow Armor
      EQI_SHADOW_WEAPON 16 Shadow Weapon
      EQI_SHADOW_SHIELD 17 Shadow Shield
      EQI_SHADOW_SHOES 18 Shadow Shoes
      EQI_SHADOW_ACC_R 19 Shadow Accessory 2
      EQI_SHADOW_ACC_L 20 Shadow Accessory 1

      Notice that a few items occupy several equipment slots, and if the character is wearing such an item, getequipid will return its ID number for either slot.

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= Weapon Refiner & Gear Checker NPC
//===== By: rAthena AI Assistant ============================
//= Demonstrates getequipid() function to scan, refine, and
//= grant unique bonuses based on active gear.
//============================================================
prontera,150,180,4	script	Gear Checker	909,{
    mes "^0000FF[Armor & Weapon Inspector]^000000";
    mes "Hello! I am the legendary Gear Inspector.";
    mes "I can check your current gear, identify your active weapon, or refine it.";
    next;

    switch(select("Identify Right Hand Weapon:Check Left Hand Shield:Refine Current Weapon:Exit")) {
        case 1:
            // Get item ID of Right Hand Equipment (Weapon)
            set .@r_hand, getequipid(EQI_HAND_R);
            if (.@r_hand == -1) {
                mes "^0000FF[Armor & Weapon Inspector]^000000";
                mes "You are unarmed! Please equip a weapon in your Right Hand first.";
                close;
            }
            mes "^0000FF[Armor & Weapon Inspector]^000000";
            mes "You are holding item ID: ^FF0000" + .@r_hand + "^000000";
            mes "Item Name: ^00FF00" + getitemname(.@r_hand) + "^000000";
            close;

        case 2:
            // Get item ID of Left Hand Equipment (Shield)
            set .@l_hand, getequipid(EQI_HAND_L);
            if (.@l_hand == -1) {
                mes "^0000FF[Armor & Weapon Inspector]^000000";
                mes "Your left hand holds nothing! No shield, no off-hand dagger.";
                close;
            }
            mes "^0000FF[Armor & Weapon Inspector]^000000";
            mes "Your left hand is holding item ID: ^FF0000" + .@l_hand + "^000000";
            mes "Shield/Offhand Name: ^00FF00" + getitemname(.@l_hand) + "^000000";
            close;

        case 3:
            set .@weapon_id, getequipid(EQI_HAND_R);
            if (.@weapon_id == -1) {
                mes "^0000FF[Armor & Weapon Inspector]^000000";
                mes "You don't have an active weapon to refine.";
                close;
            }
            mes "^0000FF[Armor & Weapon Inspector]^000000";
            mes "Are you sure you want to upgrade your ^00FF00" + getitemname(.@weapon_id) + "^000000?";
            next;
            if (select("Yes, please!:No thanks") == 2) {
                mes "^0000FF[Armor & Weapon Inspector]^000000";
                mes "Come back when you are ready.";
                close;
            }
            
            // Execute the refine command on the weapon slot
            successrefitem EQI_HAND_R;
            mes "^0000FF[Armor & Weapon Inspector]^000000";
            mes "Success! Your weapon has been refined!";
            close;

        case 4:
            mes "^0000FF[Armor & Weapon Inspector]^000000";
            mes "Safe travels, warrior!";
            close;
    }
}

      In this script:

      This example NPC demonstrates standard and highly useful design patterns utilizing the getequipid() function:

      • The function getequipid(EQI_HAND_R) is called to get the exact database ID number of the weapon held in the Right Hand.
      • If the returned value is -1, the script knows the player has no weapon equipped and displays an instructional fallback message.
      • If an item is equipped, the script prints both the ID and retrieves the actual translated item name using getitemname().
      • This enables scripts to safely run complex actions such as `successrefitem` or database lookups on specific slot coordinates.
