      eaclass()

      What is eaclass()? 🤔

      The eaclass() function evaluates and returns the specific encoded eA (eathena) job-number bitmask mapping corresponding to a given class.

      The eA job-number represents a standardized bitmask notation. Unlike standard Ragnarok job IDs (which can be scattered and non-sequential), the eA job system leverages bitmask flag constants. This makes checking character characteristics (such as whether a class is reborn, uses a baby sprite, or belongs to a specific base tree like swordsman) extremely intuitive with binary bitwise operators (&).

      If no parameters are passed, the eA job-number of the invoking character is returned by default. It returns -1 if the specified class doesn't mapped to an eA equivalent.

      Syntax of eaclass() 📜

      • eaclass({<job number>, <char_id>})

      Constants & Mappings ⚙️

      Key bitwise constants used to query the returned value (details can be found within the docs/ea_job_system.txt file):

      • EAJ_BASEMASK (0xFFF): Extracts the core base class (novice, swordsman, mage, etc.)
      • EAJL_UPPER (0x4000): Flag check for Reborn/High/Transcendence classes
      • EAJL_BABY (0x8000): Flag check for Baby level character classes
      • EAJ_UPPERMASK (0x3FFF): Mask filters out the reborn status, grouping base, job-1, and job-2 types cleanly.

      Example Usage 💡

      Example Code:
      prontera,150,150,4	script	eA Class Checker	99,{
    mes "^0000FF[eA Classifier]^000000";
    
    // Retrieve the eA job bitmask of the player
    set .@eac, eaclass();
    
    // Check if the base job under the mask belongs to Swordsman (EAJ_SWORDMAN)
    if ((.@eac & EAJ_BASEMASK) == EAJ_SWORDMAN) {
        mes "Your core fundamental class lineage is Swordsman!";
    }
    
    // Check reborn status flag EAJL_UPPER
    if (.@eac & EAJL_UPPER) {
        mes "You have unlocked the powerful Reborn/Transcendence class features!";
    }
    
    // Check upper mask grouping (will be true for Swordsman, High Swordsman, Baby Swordsman)
    if ((.@eac & EAJ_UPPERMASK) == EAJ_SWORDMAN) {
        mes "You belong under the broader Swordsman developmental umbrella.";
    }
    
    close;
}

      In this script:

      • On line 5, eaclass() extracts the custom binary bitmask mapping of the calling player.
      • On line 8, (.@eac & EAJ_BASEMASK) == EAJ_SWORDMAN performs a bitwise AND operation to isolate the base job type and compare it.
      • On line 13, .@eac & EAJL_UPPER checks if the high-tier reborn bit is set in the player's class bitmask.
