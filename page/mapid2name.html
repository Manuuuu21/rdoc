      mapid2name()

      What is mapid2name? 🤔

      The mapid2name() function accepts a numeric **Map ID** and returns the string identifier/name of that map registered in the emulator's database config registries.

      This is exceptionally helpful for systems that store map designations purely as numerical values or IDs in save data files, or logs, and then need to look up or display the human-readable map name in an NPC chat bubble.

      Syntax of mapid2name? 📜

      • mapid2name(<map ID>)

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      <map ID> Integer The unique internal numerical identifier index representing a physical or instance map in rAthena memory.

      Return Value ↩️

      • Returns the **String designation of the map** (such as "prontera" or "morroc") if the map ID corresponds to a valid, loaded map index definitions.
      • Returns an **empty string ("")** if the supplied Map ID doesn't exist or isn't active on the emulator.

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= Map ID Converter Tool NPC
//===== By: rAthena AI Assistant ============================
//= Showcases mapid2name() to convert map indices to strings
//============================================================
prontera,160,180,4	script	Map Finder Assistant	909,{
    mes "^0000FF[Map Finder]^000000";
    mes "Greetings! Do you have a map index ID you would like me to resolve?";
    next;

    if (select("Yes, translate ID:No thanks") == 2) {
        mes "^0000FF[Map Finder]^000000";
        mes "Have a pleasant day!";
        close;
    }

    mes "^0000FF[Map Finder]^000000";
    mes "Excellent. Please input the numerical Map ID index below:";
    next;

    input .@target_map_id;

    // Call the translator function
    set .@resolved_name$, mapid2name(.@target_map_id);

    if (.@resolved_name$ == "") {
        mes "^0000FF[Map Finder]^000000";
        mes "Oh, dear! The Map ID ^FF0000" + .@target_map_id + "^000000 does not point to any active maps. Please check your rAthena configuration files.";
        close;
    }

    mes "^0000FF[Map Finder]^000000";
    mes "Search success!";
    mes "Map Index: ^0055FF" + .@target_map_id + "^000000";
    mes "Resolved Map Name: ^00FF00" + .@resolved_name$ + "^000000";
    close;
}

      In this script:

      This map finder assistant utilizes clean index matching:

      • The function mapid2name(.@target_map_id) executes an internal check against the map register hash table.
      • If found, it returns the standard name layout, otherwise returning an empty string. The script uses this return state (if (.@resolved_name$ == "")) to inform the user that the ID is invalid.
