      PC Logout Event Script

      LogoutHandler is a floating NPC that reacts when a player logs out. It checks the fishing flag stored at isFishing[getcharid(3)], clears that flag when it is set, and writes a message containing the character's name to the server debug output.

      How this script works

      1. The floating NPC uses - instead of map coordinates, so it has no clickable NPC on a map.
      2. OnPCLogoutEvent runs the handler for the departing player.
      3. getcharid(3) supplies the account ID used as the array index in this sample.
      4. If the indexed value is nonzero, the script sets it to 0 and uses debugmes to record the logout.

      Configuration

      SettingCurrent valueExplanation
      EventOnPCLogoutEventThe entry point for logout handling.
      FlagisFishing[getcharid(3)]The fishing script must use the same variable and index for this check to find its state.
      Reset value0Marks the indexed fishing flag as inactive.
      Log namestrcharinfo(0)The character name included in the debug message.

      Integration: This handler only clears the flag shown above. It does not cancel timers or clear @AutoFishing. Match the cleanup to the variables used by the fishing system you are integrating.

      Example Code:
      //===== rAthena Script =======================================
//= LogoutHandler
//===== By: rAthena AI Assistant ============================
//= Handles player logout events.
//============================================================
-	script	LogoutHandler	-,{
    OnPCLogoutEvent:
        if (isFishing[getcharid(3)]) {
            isFishing[getcharid(3)] = 0;
            debugmes "" + strcharinfo(0) + " has logout when doing fishing!";
        }
    end;
}
