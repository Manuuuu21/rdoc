      Shadow Item Trader

      Shadow Item Trader is an NPC at Prontera (164, 164) that opens a shop for Shadow equipment. Its itemshop definition uses item 7615 as the payment currency, with every listed piece priced at 10 units of that item.

      How this script works

      1. The player selects “Costume Shadow Item” from the NPC’s menu.
      2. callshop "cShadowItem",0 opens the matching item shop.
      3. The itemshop declaration specifies the currency item first, followed by the equipment IDs and their costs.
      4. OnInit creates a “Shadow Item Trader” label above the NPC with waitingroom.

      Configuration

      SettingCurrent valueExplanation
      NPC locationprontera,164,164,3Map, X coordinate, Y coordinate, and facing direction.
      Shop namecShadowItemMust match the shop referenced by callshop.
      Currency item7615The item consumed as payment by this item shop.
      Listed cost10 per pieceThe number after the colon in each equipment entry.

      Example: The entry 24243:10 lists item 24243 for 10 units of currency item 7615. Edit the currency ID or the individual item-and-cost pairs to change the exchange.

      Example Code:
      //===== rAthena Script =======================================
//= Shadow Item Trader
//===== By: rAthena AI Assistant ============================
//= Provides a shop for Shadow Items.
//============================================================
prontera,164,164,3	script	Shadow Item Trader	564,{
    switch(select("Costume Shadow Item")) {
        case 1:
            callshop "cShadowItem",0;
            end;
            break;
    }
    OnInit:
        waitingroom "Shadow Item Trader",0;
    end;
}
