      Rune Skill Trader

      Rune Stone Trader is an NPC at Midgard Camp (mid_camp, 250, 239). After a short conversation with Marvin, it opens a Zeny shop containing nine Rune Stone item IDs, each listed at 50,000 Zeny in the supplied shop definition.

      How this script works

      1. The NPC displays its dialogue with mes and waits for the player to continue with next.
      2. callshop "Bokie_Shop",1 opens the shop’s buying interface.
      3. The separate shop declaration defines the stock using itemID:price pairs.
      4. The shop handles the purchase, while the NPC dialogue ends with end.

      Configuration

      SettingCurrent valueExplanation
      NPC locationmid_camp,250,239,3Map, X coordinate, Y coordinate, and facing direction.
      Shop nameBokie_ShopMust match the name passed to callshop.
      Stock item IDs12732, 12725–12731, 12733The nine item IDs in the shop definition.
      Listed unit price50000 ZenyChange the price after each item’s colon to adjust its listed cost.

      Customization: Add or remove itemID:price pairs in Bokie_Shop to change the inventory. Keep both the dialogue NPC and the shop declaration loaded so callshop can find its target.

      Example Code:
      //===== rAthena Script =======================================
//= Rune Stone Trader
//===== By: rAthena AI Assistant ============================
//= Sells Rune Stone Items.
//============================================================
mid_camp,250,239,3	script	Rune Stone Trader	735,{
    set @name$, "[^1100AA Marvin ^000000]";
    mes @name$;
    mes "Hello!, my name is Marvin";
    mes "I create and sell Rune Stone Items.";
    mes "Look and Choose whatever you want.";
    next;
    callshop "Bokie_Shop",1;
    end;
}

//===== rAthena Shop =========================================
//= Bokie_Shop
//===== By: rAthena AI Assistant ============================
//= Shop definition for Rune Stone Trader.
//============================================================
-	shop	Bokie_Shop	-,12732:50000,12725:50000,12726:50000,12727:50000,12728:50000,12729:50000,12730:50000,12731:50000,12733:50000;
