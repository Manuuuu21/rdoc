    Showcase Scripts



      rentitem, rentitem2, rentitem3, rentitem4

      What are Rental Items? ⏱️ 🤔

      The rentitem command family creates a temporary rental item inside the attached character's inventory bag. The item will automatically expire in <time> seconds and be permanently deleted.

      When receiving a rental item, the character gets notified via a chat message. Standard systemic warning countdown logs will pop up in their chat screen before the item vanishes.

      Security & Execution safeguards 🛑

      • Rental commands CANNOT be used on stackable items (such as potions or arrows).
      • Rental items are locked against drop commands, merchant shop vending, player trade, and guild storage registers (default trade mask: 67).
      • UnUnequipped triggers are fully validated. When rentals expire, the game calls the UnEquipScript of the item database, allowing resetting of secondary buffs, custom status changes, or vars.
      • Standard item counting routines (countitem) will NOT look into items with active rental timers. You must use rentalcountitem to count active rental items.

      Syntax Specifications 📜

      1. rentitem (Basic Rental)

      • rentitem <item id>,<time>{,<account_id>};
      • rentitem "<item name>",<time>{,<account_id>};

      2. rentitem2 (Advanced Rental)

      • rentitem2 <item id>,<time>,<identify>,<refine>,<attribute>,<card1>,<card2>,<card3>,<card4>{,<account_id>};

      3. rentitem3 (Random Options Rental)

      • rentitem3 <item id>,<time>,<identify>,<refine>,<attribute>,<card1>,<card2>,<card3>,<card4>,<RandomIDArray>,<RandomValueArray>,<RandomParamArray>{,<account_id>};

      4. rentitem4 (Enchant Grade Rental)

      • rentitem4 <item id>,<time>,<identify>,<refine>,<attribute>,<card1>,<card2>,<card3>,<card4>,<grade>,<RandomIDArray>,<RandomValueArray>,<RandomParamArray>{,<account_id>};

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= Trial Gear Provisioner NPC
//============================================================
prontera,150,150,4	script	Trial Officer	99,{
    mes "^0000FF[Trial Officer]^000000";
    mes "Want to rent our legendary lance for exactly 1 hour?";
    next;
    
    if (select("Yes, please!:No, cancel") == 2) {
        mes "^0000FF[Trial Officer]^000000";
        mes "Fine, trials are strictly for brave souls.";
        close;
    }
    
    // Rent a Gungnir Spear (ID: 1410) for 1 hour (3600 seconds)
    rentitem 1410, 3600;
    
    mes "^0000FF[Trial Officer]^000000";
    mes "The lance is yours! It will automatically crumble in 3600 seconds.";
    close;
}

      In this script:

      • On line 12, calling rentitem 1410, 3600 injects Gungnir into the player's inventories. A countdown starts immediately, and the item will delete itself from their inventory exactly 60 minutes later.
      Example 2: Advanced rentitem4
      //===== rAthena Script =======================================
//= Temporary Advanced Gear
//============================================================
setarray .@opts, 4700; // Option
setarray .@vals, 10;   // Value
setarray .@prms, 0;    // Para

// ID 1410 (Gungnir), Time 1800s, Ident 1, Refine 10, Broken 0, Cards 0... Grade B
rentitem4 1410, 1800, 1, 10, 0, 0,0,0,0, ENCHANTGRADE_B, .@opts, .@vals, .@prms;

      In this script:

      • Uses rentitem4 to dynamically create a temporary rental item with advanced stats, enchant grade B, and random options for 30 minutes.
