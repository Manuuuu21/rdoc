      getitembound, getitembound2, getitembound3, getitembound4

      What does Bounding do? 🛡️ 🤔

      The getitembound command functions identically to the standard getitem commands family, except the created items will be strictly bound to the target character according to the specified bound type.

      Bounded items automatically acquire non-tradeable, non-mailable, non-auctionable protective locks and in specific styles can't even be placed inside general server storage chests.

      Bound Types constants ⚙️

      These valid bound type constants are mapped within the script constants catalog:

      • Bound_Account (1): Account Bound. Shareable across characters of the same login account via Koffry/Storage, but not tradable.
      • Bound_Guild (2): Guild Bound. Lock associated with active Guild status.
      • Bound_Party (3): Party Bound. Lock linked to Party status.
      • Bound_Char (4): Character Bound. Absolute personal lock; cannot be stored or traded; locked to the character slot alone.

      Syntax Specifications 📜

      1. getitembound (Standard Bound)

      • getitembound <item id>,<amount>,<bound type>{,<account ID>};
      • getitembound "<item name>",<amount>,<bound type>{,<account ID>};

      2. getitembound2 (Advanced Bound)

      • getitembound2 <item id>,<amount>,<identify>,<refine>,<attribute>,<card1>,<card2>,<card3>,<card4>,<bound type>{,<account ID>};

      3. getitembound3 (Random Option Bound)

      • getitembound3 <item id>,<amount>,<identify>,<refine>,<attribute>,<card1>,<card2>,<card3>,<card4>,<bound type>,<RandomIDArray>,<RandomValueArray>,<RandomParamArray>{,<account ID>};

      4. getitembound4 (Enchant Grade Bound)

      • getitembound4 <item id>,<amount>,<identify>,<refine>,<attribute>,<card1>,<card2>,<card3>,<card4>,<bound type>,<grade>,<RandomIDArray>,<RandomValueArray>,<RandomParamArray>{,<account ID>};

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= Guild Event reward distributor
//============================================================
prontera,150,150,4	script	Prize Giver	99,{
    mes "^0000FF[Guild Recruiter]^000000";
    mes "Hello! Since you completed our challenge, here is your prize!";
    next;
    
    // Give 1 customized Elven Bow (ID: 1718) as Account Bound item (Bound_Account)
    getitembound 1718, 1, Bound_Account;
    
    mes "^0000FF[Guild Recruiter]^000000";
    mes "It is bound on your account securely so you cannot trade or lose it.";
    close;
}

      In this script:

      • On line 9, getitembound 1718, 1, Bound_Account distributes 1 account-bound Elven Bow, preventing drops or player-to-player transfers.
