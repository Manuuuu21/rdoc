      heal, percentheal

      What are heal & percentheal? 🤔

      The heal and percentheal commands restore physical Hit Points (HP) and Spell Points (SP) to the player character session.

      • heal restores an **exact raw numeric amount** of flat HP/SP.
      • percentheal restores a **percentage** of the target character's maximum HP/SP, making scaling extremely balanced for high-level vs low-level players.

      No Visuals: Both commands alter the raw player state variables silently and immediately, producing no visual special effects or animation circles natively. To generate visual animations, pair these with specialeffect!

      Syntaxes 📜

      • heal <hp>,<sp>{,<char_id>};
      • percentheal <hp percent>,<sp percent>{,<char_id>};

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      <hp> / <hp percent> Integer Flat amount of HP (for heal) or percentage from 1 to 100 (for percentheal) to restore.
      <sp> / <sp percent> Integer Flat amount of SP (for heal) or percentage from 1 to 100 (for percentheal) to restore.
      <char_id> (Optional) Integer Database character ID number of the target player. If omitted, healing applies strictly to the invoking player.

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= Traditional Restoration & Healer Coach
//= Showcases flat heal and percentage percentheal differences
//============================================================
prontera,160,180,4	script	Spiritual Healer	99,{
    mes "^0000FF[Spiritual Healer]^000000";
    mes "Greetings, weary gladiator. My restorative light is yours.";
    mes "What form of spiritual healing do you require?";
    next;
    
    set .@sel, select("Give me flat revitalization! (Flat 10k HP):Restore half my vital limits! (50% HP):Cancel");
    
    if (.@sel == 1) {
        // Flat restoration of 10000 HP and 1000 SP
        heal 10000, 1000;
        specialeffect 15; // Restoration animation visual
        dispbottom "Healed flat 10,000 HP and 1,000 SP safely!";
    } 
    else if (.@sel == 2) {
        // Percentage restoration of 50% HP and 50% SP
        percentheal 50, 50;
        specialeffect 416; // Big healing green light bloom animation
        dispbottom "Percentage Restoration: 50% max HP/SP recovered!";
    }
    
    mes "^0000FF[Spiritual Healer]^000000";
    mes "Your vitality has been fully re-aligned. Safe battles!";
    close;
}

      In this script:

      • On line 14, heal 10000, 1000 recovers flat numeric limits immediately.
      • On line 20, the command percentheal 50, 50 reads the player's maximum bounds and scales the restoration dynamically, creating an elite experience for high-end players.
