      attachrid, detachrid

      What are attachrid & detachrid? 🤔

      The attachrid() and detachrid commands allow scripts to explicitly manipulate the currently attached character session (the Requesting ID or RID).

      When a script starts via floating commands, timing events, or standard system triggers, there may be no player session associated with the execution thread. Alternatively, a script might need to perform operations on a different online player.

      • attachrid() links an online player to the running script session using their character's account ID (RID).
      • detachrid; completely releases the attached player from the active scripting context, causing subsequent player-specific parameters or commands to behave as if no player is online.

      Syntax 📜

      • attachrid(<account ID>{,<force>})
      • detachrid;

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      <account ID> Integer The account identification number (not character ID) of the target player to attach.
      <force> (Optional) Boolean Determines attachment force. If set to true (default), attaches the player even if they are currently executing other script dialogue/menus. If false, fails if a script window is busy.

      Return Values ↩️

      attachrid() returns true if the player attached successfully (i.e. is online/valid), or false upon failure.

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= Global Broadcast & Remote Gift Sender
//= Demonstrates attachrid and detachrid to message players
//============================================================
prontera,160,160,4	script	Remote Gifter	110,{
    mes "^0000FF[Gift Warden]^000000";
    mes "input an Account ID to send them a gift pouch remotely!";
    next;
    
    input .@target_rid;
    
    // Save current active player's RID to return to later
    set .@original_rid, getcharid(3);
    
    // Attempt attachment to target without force override
    if (!attachrid(.@target_rid, false)) {
        mes "Error: That player is currently offline or busy!";
        close;
    }
    
    // Commands here now affect the target player!
    getitem 501, 1; // Gives Red Potion to target player!
    dispbottom "You have received a gift from Account ID " + .@original_rid + "!";
    
    // Detach target player session
    detachrid;
    
    // Re-attach original invoking character to resume dialogue
    attachrid(.@original_rid);
    
    mes "^0000FF[Gift Warden]^000000";
    mes "Success! Gift pouch delivered safely.";
    close;
}

      In this script:

      The Remote Gifter session hops seamlessly:

      • The invoking player's raw ID is stored using getcharid(3) on line 12.
      • The target is linked securely using attachrid(.@target_rid, false) on line 15. If offline, the transaction is rejected gracefully.
      • Items can be added directly to the target's gear using getitem.
      • Calling detachrid on line 22 resets session pointers securely, before restoring the original speaker's status on line 25.
