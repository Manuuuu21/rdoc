      getmapusers()

      What is getmapusers? 🤔

      The getmapusers() function retrieves the total count of connected players currently present on the explicitly specified map name.

      This command is extensively utilized officially on PvP maps, custom instanced lobby hubs, or item event maps to verify whether a restricted room is currently empty, or if it has reached its maximum player capacity before attempting to teleport new characters inside.

      Syntax of getmapusers? 📜

      • getmapusers("<map name>")

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      "<map name>" String The legal string key representing the target physical or instance map (e.g. "prontera" or "guild_vs1").

      Return Value ↩️

      • Returns an **integer** representing the player head-count active on the target map.
      • Returns **0** if there are no players on that map, or if the specified map name is invalid or not loaded by the map server.

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= Restricted PvP Arena Doorman NPC
//===== By: rAthena AI Assistant ============================
//= Showcases getmapusers() to enforce capacity limits
//============================================================
prontera,150,180,4	script	PvP Gatekeeper	909,{
    mes "^0000FF[PvP Gatekeeper]^000000";
    mes "Greetings, gladiator! I control entry into the exclusive PvP Combat Coliseum.";
    mes "This arena is limited to a maximum of ^FF000020 players^000000 simultaneously.";
    next;

    // Fetch head-count on the PvP map "guild_vs1"
    set .@arena_count, getmapusers("guild_vs1");

    mes "^0000FF[PvP Gatekeeper]^000000";
    mes "The coliseum currently contains: ^00FF00" + .@arena_count + " / 20^000000 players.";
    next;

    if (.@arena_count >= 20) {
        mes "^0000FF[PvP Gatekeeper]^000000";
        mes "I am sorry, but the coliseum is filled to maximum capacity right now!";
        mes "Wait a moment for some players to leave, and try again.";
        close;
    }

    mes "^0000FF[PvP Gatekeeper]^000000";
    mes "Are you prepared to join the fray?";
    next;

    if (select("Yes, warp me in!:No, I am scared") == 1) {
        warp "guild_vs1", 50, 50;
        end;
    }

    mes "^0000FF[PvP Gatekeeper]^000000";
    mes "No problem. Come back when you find your courage!";
    close;
}

      In this script:

      The Gatekeeper NPC illustrates clean entry guarding:

      • The command getmapusers("guild_vs1") retrieves a precise snapshot of active players situated in the map zone on line 10.
      • We enforce standard bounds (if (.@arena_count >= 20)) to preserve CPU performance and keep fighting ratios highly balanced for gameplay security.
