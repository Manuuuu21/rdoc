      getequiprefinerycnt()

      What is getequiprefinerycnt? 🤔

      The getequiprefinerycnt() function retrieves the current refinement level (the number of pluses, e.g. +4, +7, +10) of the item equipped in the specified equipment slot on the character.

      If no item is equipped in the target equipment slot, or if the equipped item has not been refined at all, the function returns 0.

      Syntax of getequiprefinerycnt? 📜

      • getequiprefinerycnt(<equipment slot>{,<char_id>})

      Syntax Parameter Explanation 🧩

      • <equipment slot>: The target slot constant to query. This must be a valid equipment location constant such as EQI_HEAD_TOP, EQI_ARMOR, EQI_HAND_R, etc. For a complete list of slot constants and their numerical values, refer to the getequipid() documentation page.
      • <char_id> (Optional): The character ID of the player whose equipment you want to inspect. If omitted, the check defaults to the active character currently invoking the script.

      Return Value ↩️

      Equipped State Refine Level Return Value
      No item is equipped in the specified slot N/A 0
      An item is equipped, but was never refined +0 0
      A refined item is equipped +N (e.g. +7, +10) N (e.g. 7, 10)

      Purpose & Practical Uses 🎯

      This function is the primary gatekeeper when building custom blacksmithing and equipment upgrading systems in Ragnarok Online:

      • Safety Limits: Prevent refining characters' gear past maximum server limits (e.g., stopping refines above +10).
      • Tiered Upgrade Costs: Scale the required refining materials or Zeny fees dynamically depending on the active plus value of the item.
      • Refinement Set Bonuses: Grant unique achievements, titles, or item bonuses if a character is wearing items to high refinement thresholds (e.g. getequiprefinerycnt(EQI_ARMOR) >= 9).

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= Elite Refiner & Upgrader NPC
//===== By: rAthena AI Assistant ============================
//= Demonstrates getequiprefinerycnt() to safely inspect
//= and limit item refinement levels.
//============================================================
prontera,150,185,4	script	Elite Refiner	909,{
    mes "^0000FF[Elite Refiner]^000000";
    mes "Greetings, challenger! I am the Elite Blacksmith.";
    mes "I can safely upgrade your Upper Headgear, but only if it is below +10.";
    next;

    if (select("Examine Upper Headgear:Cancel") == 2) {
        mes "^0000FF[Elite Refiner]^000000";
        mes "Suit yourself! Come back when you wish to hone your power.";
        close;
    }

    // Check if an item is equipped there
    if (getequipid(EQI_HEAD_TOP) == -1) {
        mes "^0000FF[Elite Refiner]^000000";
        mes "Wait a second... you aren't wearing anything on your head!";
        close;
    }

    // Obtain current refine count of the item
    set .@refine_level, getequiprefinerycnt(EQI_HEAD_TOP);
    mes "^0000FF[Elite Refiner]^000000";
    mes "Excellent! Your ^00FF00" + getequipname(EQI_HEAD_TOP) + "^000000 is currently refined to ^FF0000+" + .@refine_level + "^000000.";
    next;

    // Reject if current refinement has hit maximum limit of 10
    if (.@refine_level >= 10) {
        mes "^0000FF[Elite Refiner]^000000";
        mes "Wow! It is already perfected (+10 or higher). I cannot refine this any further!";
        close;
    }

    mes "^0000FF[Elite Refiner]^000000";
    mes "Would you like me to upgrade it right now for 5,000 Zeny?";
    next;

    if (select("Yes, refine it!:No thanks") == 2) {
        mes "^0000FF[Elite Refiner]^000000";
        mes "Perhaps another time.";
        close;
    }

    if (Zeny < 5000) {
        mes "^0000FF[Elite Refiner]^000000";
        mes "You do not have enough Zeny to cover the service fee.";
        close;
    }

    set Zeny, Zeny - 5000;
    
    // Attempt refine action
    successrefitem EQI_HEAD_TOP;
    
    mes "^0000FF[Elite Refiner]^000000";
    mes "Clang! Clang! Clang!";
    mes "Success! Your headgear is now ^00FF00+" + getequiprefinerycnt(EQI_HEAD_TOP) + "^000000!";
    close;
}

      In this script:

      This example Elite Refiner NPC illustrates highly optimal workflow conventions for refinement:

      • The function getequipid(EQI_HEAD_TOP) is first checked to ensure the player actually has a helmet equipped in the Upper Headgear slot.
      • We retrieve the current refinement level using getequiprefinerycnt(EQI_HEAD_TOP).
      • We apply conditional checking (if (.@refine_level >= 10)) to prevent the player from refining a perfected weapon or armor piece beyond the safe limit.
