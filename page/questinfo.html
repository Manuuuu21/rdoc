      questinfo

      What is questinfo? 🤔

      This command should only be used in OnInit/OnInstanceInit labels. Show an emotion on top of a NPC, and optionally, a colored mark in the mini-map like "viewpoint" or "viewpointmap". When a user is doing some action, each NPC is checked for questinfo that has been set on the map. If questinfo is present, it will check if the player fulfill the condition. If he/she does or no condition has been set, the bubble will appear.

      <Map Mark Color>, when used, creates a mark in the user's mini map on the position of the NPC, the available color values are:

      <condition> can be any expression similarly to the <condition> in the if command.

      List of the player's actions to trigger the questinfo condition: - Item added to/removed from player inventory - Base/Job level change - Job change - Quest given/erased/completed - Quest objective updated (character killed a monster quest target) - Warp

      Syntax of questinfo 📜

      • questinfo <Icon>{,<Map Mark Color>{,"<condition>"}};

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      <Icon> Constant / Integer The quest icon constant to display above the NPC (e.g., QTYPE_QUEST, QTYPE_EVENT).
      <Map Mark Color> (Optional) Constant / Integer The mini-map marker color constant (e.g., QMARK_NONE, QMARK_YELLOW).
      "<condition>" (Optional) Expression <condition> can be any expression similarly to the <condition> in the if command.

      Constants & Options ⚙️

      Available <Icon>:

      Constant / Value Description
      No Icon QTYPE_NONE
      ! Quest Icon QTYPE_QUEST
      ? Quest Icon QTYPE_QUEST2
      ! Job Icon QTYPE_JOB
      ? Job Icon QTYPE_JOB2
      ! Event Icon QTYPE_EVENT
      ? Event Icon QTYPE_EVENT2
      Warg QTYPE_WARG (Only for packetver < 20170315)

      Constant / Value Description
      QMARK_NONE No Marker (default)
      QMARK_YELLOW Yellow Marker
      QMARK_GREEN Green Marker
      QMARK_PURPLE Purple Marker

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= questinfo Example Script
//= Demonstrates usage of questinfo
//============================================================
izlude,100,100,4	script	Test	844,{
	mes "[Test]";
	mes "Hello World.";
	close;

OnInit:
	// Display an icon if the player has completed the given hunting quest and his/her variable 'unknown_var' is above 0
	questinfo QTYPE_QUEST, QMARK_YELLOW, "checkquest(1001,HUNTING) == 2 && unknown_var > 0";

	//.. or display an icon if the player didn't start the given quest and he/she has one red potion in inventory
	questinfo QTYPE_QUEST, QMARK_YELLOW, "!isbegin_quest(1001) && countitem(501) == 1";
	end;
}

      In this script:

      • The script defines an NPC object on prontera (or the target map) that triggers when a player interacts with it.
      • It invokes questinfo with the required arguments as specified in the rAthena scripting reference.
      • Any resulting state change, return value, or player/unit update is processed immediately within the active script execution context.
