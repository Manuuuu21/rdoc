      while

      What is while? 🤔

      This is probably the simplest and most frequently used loop structure. The while statement can be interpreted as "while <condition> is true, perform <statement>". It is a pretest loop, meaning the conditional expression is tested before any of the statements in the body of the loop are performed. If the condition evaluates to false, the statement(s) in the body of the loop is/are never executed. If the condition evaluates to true, the statement(s) are executed, then control transfers back to the conditional expression, which is reevaluated and the cycle continues.

      Multiple statements can be grouped with { }, curly braces, just like with the if statement.

      Syntax of while 📜

      • while (<condition>) <statement>;

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      <condition> Expression <condition> is true, perform <statement>".
      <statement> Statement A single script statement or a block of statements enclosed in { ... }.

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= while Demonstration NPC
//= Demonstrates how to use while
//============================================================
prontera,150,150,4	script	WhileDemo	100,{
    mes "[WhileDemo]";
    while (switch(select("Yes:No") == 2 ))
            mes "You picked no.";
        close;
}

      In this script:

      • The script defines an NPC object on prontera (or the target map) that triggers when a player interacts with it.
      • It invokes while with the required arguments as specified in the rAthena scripting reference.
      • Any resulting state change, return value, or player/unit update is processed immediately within the active script execution context.
      Example 2:
      //===== rAthena Script =======================================
//= while Demonstration NPC
