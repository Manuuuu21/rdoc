      warpwaitingpc

      What is warpwaitingpc? 🤔

      This command will warp the amount of characters equal to the trigger number of the waiting room chat attached to the NPC object running this command to the specified map and coordinates, kicking them out of the chat. Those waiting the longest will get warped first. It can also do a random warp on the same map ("Random" instead of map name) and warp to the save point ("SavePoint").

      The list of characters to warp is taken from the list of the chat room members. Those not in the chat room will not be considered even if they are talking to the NPC in question. If the number of people is given, exactly this much people will be warped.

      This command can also keep track of who just got warped. It does this by setting special variables:

      $@warpwaitingpc[] is an array containing the account_id numbers of the characters who were just warped. $@warpwaitingpcnum contains the number of the character it just warped.

      Note: See also getpartymember for advice on what to do with those variables.

      The obvious way of using this effectively would be to set up a waiting room for two characters to be warped onto a random PVP map for a one-on-one duel, for example.

      Syntax of warpwaitingpc 📜

      • warpwaitingpc "<map name>",<x>,<y>{,<number of people>};

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      "<map name>" String The name of the target map (e.g., "prontera").
      <x> Integer The X coordinate on the map.
      <y> Integer The Y coordinate on the map.
      <number of people> (Optional) Integer Specifies the <number of people> parameter for warpwaitingpc.

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= warpwaitingpc Demonstration NPC
//= Demonstrates how to use warpwaitingpc
//============================================================
prontera,150,150,4	script	WarpwaitingpcDemo	100,{
    mes "^0000FF[WarpwaitingpcDemo]^000000";
    mes "Testing the warpwaitingpc command.";
    next;

    warpwaitingpc "prontera", 150, 150;
    mes "Executed warpwaitingpc successfully!";
    close;
}

      In this script:

      • The script defines an NPC object on prontera (or the target map) that triggers when a player interacts with it.
      • It invokes warpwaitingpc with the required arguments as specified in the rAthena scripting reference.
      • Any resulting state change, return value, or player/unit update is processed immediately within the active script execution context.
