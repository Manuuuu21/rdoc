      chatmes()

      What is chatmes? 🤔

      The chatmes() command displays a message in the active waiting room (chat room) of an NPC. This is widely used for sending notifications, game countdowns, or status updates to all players who are currently waiting inside the chat room.

      Note: If the target NPC is not currently hosting a waiting room, or if a player is not inside the waiting room, this command will fail silently and nothing happens.

      Syntax of chatmes? 📜

      • chatmes "<message>"{,"<NPC name>"};

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      "<message>" String The message text to broadcast to players in the waiting room chat.
      "<NPC name>" (Optional) String The unique object name of the target NPC. If specified, that NPC's waiting room will display the message. If omitted, the currently attached NPC running the script is used.

      Example Usage 💡

      Example Code:
      //=====	rAthena Script	=======================================
//=	Waiting Room Broadcaster & Chat Announcer
//=	Periodically announces waiting room status updates
//============================================================
prontera,150,150,4	script	WaitingRoomAnnouncer	99,{
    mes "^0000FF[Room Manager]^000000";
    mes "Hello! I manage the waiting room for the Battleground.";
    mes "Let me broadcast a message to everyone inside.";
    next;

    // Send a message to everyone in the waiting room
    chatmes "Waiting 5 minutes until the next match will start";

    mes "^0000FF[Room Manager]^000000";
    mes "Message successfully sent to the waiting room!";
    close;
}

      In this script:

      • The script initializes a standard rAthena NPC named WaitingRoomAnnouncer.
      • We execute the chatmes command on line 11 to display a broadcast message inside the waiting room.
      • Every player sitting or waiting in the chat room (waitingroom) of this NPC will instantly see the text "Waiting 5 minutes until the next match will start" in their chat window.
      • If the NPC does not currently possess an active waiting room, the command fails silently without causing errors or server crashes.
