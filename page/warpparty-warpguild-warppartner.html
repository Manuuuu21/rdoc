      warpparty, warpguild, warppartner

      What are warpparty, warpguild, & warppartner? 🤔

      These three cooperative teleportation commands allow script writers to instantly warp whole player groups (Parties, Guilds, or Marriage Partners) to specified maps and coordinates simultaneously.

      Syntaxes 📜

      • warpparty("<to_mapname>",<x>,<y>,<party_id>,{"<from_mapname>"{,<range x>,<range y>}});
      • warpguild("<to_mapname>",<x>,<y>,<guild_id>);
      • warppartner("<to_mapname>",<x>,<y>);

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      "<to_mapname>" String The destination map name. Supports special values described below.
      <x>, <y> Integer Coordinates on the destination map. Setting these to 0,0 teleports players to random coordinate cells.
      <party_id> / <guild_id> Integer The unique database identification number of the party or guild to teleport. Retrieve using getcharid(1) for party or getcharid(2) for guild.
      "<from_mapname>" (Optional) String Filters selected members: only party members situated on this source map will be warped.
      <range x>, <range y> (Optional) Integer Enables coordinate randomization around (x,y) by adding/subtracting a random offset.

      Special Map Identifiers 📍

      Special Keyword Effect/Behavior
      "Random" Warp each target randomly on their **current** map (simulates using a fly wing independently).
      "SavePointAll" Warp all targets back to their respective personal save coordinates.
      "SavePoint" Warp all targets directly to the save point of the current invoking/attached character.
      "Leader" Warp all members to the party leader's current position (only works for warpparty if the leader is online on the same map-server).
      "RandomAll" Warp all members to the **same** random coordinates in their current map.

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= Instant Group Warper Master
//= Demonstrates warpparty, warpguild and warppartner
//============================================================
prontera,155,150,4	script	Alliance Teleporter	99,{
    mes "^0000FF[Alliance Teleporter]^000000";
    mes "Greetings! I can teleport your entire party, guild, or your beloved partner!";
    next;
    
    set .@menu_sel, select("Warp Party (Morroc):Warp Guild (Geffen):Warp Spouse (My Position):Quit");
    
    if (.@menu_sel == 1) {
        set .@party, getcharid(1);
        if (.@party == 0) {
            mes "Error: You are not currently in a party!";
            close;
        }
        warpparty "morocc", 150, 150, .@party;
    } 
    else if (.@menu_sel == 2) {
        set .@guild, getcharid(2);
        if (.@guild == 0) {
            mes "Error: You are not currently in a guild!";
            close;
        }
        warpguild "geffen", 100, 100, .@guild;
    } 
    else if (.@menu_sel == 3) {
        // Fetch current coordinates of active player to warp spouse there
        getmapxy .@map$, .@x, .@y, 0;
        if (warppartner(.@map$, .@x, .@y)) {
            dispbottom "Spouse teleport sequence initiated!";
        } else {
            mes "Error: Your spouse is currently offline or you are not married!";
            close;
        }
    }
    
    mes "^0000FF[Alliance Teleporter]^000000";
    mes "Teleport completes! Farewell!";
    close;
}

      In this script:

      • On line 16, the command warpparty grabs the player's party ID and teleports all active party members directly to morocc.
      • On line 24, warpguild teleports all guild members directly of the invoking player's guild ID to geffen.
      • On line 29, warppartner attempts to dynamically locate and pull the marital spouse over to the active player's exact coordinates.
