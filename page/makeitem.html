      makeitem, makeitem2, makeitem3, makeitem4

      What are makeitem, makeitem2, makeitem3, makeitem4? 🤔

      This command will create an item on the specified cell of a map.

      As with any dropped items, the items created with this command will disappear after a period of time. Using an amount greater than 1 will create a single stack of the given amount, not multiple stacks of 1.

      Like getitem, it also accepts an 'english name' field from the database and creates Apples if the name isn't found. If the map name is given as "this", the map the invoking character is on will be used. If <canShowEffect> flag is set to true, it will show a pillar effect on the ground when dropped, depending on the item database's DropEffect flag.

      This command will create an item on the specified cell of a map. See makeitem for further details.

      See getitem2 for an explanation of the expanded parameters.

      makeitem3 is advance version of makeitem2 that also use Item Random Option as additional values. <RandomIDArray> : Array variable of ID for item random option, see db/[pre-]re/item_randomopt_db.yml <RandomValueArray> : Array variable of item random option's value. <RandomParamArray> : Array variable of item random option's param.

      makeitem4 is advance version of makeitem3 that also use the grade as additional values. Valid grades are:

      Syntax of makeitem, makeitem2, makeitem3, makeitem4 📜

      • makeitem <item id>,<amount>,"<map name>",<X>,<Y>{,<canShowEffect>};
      • makeitem "<item name>",<amount>,"<map name>",<X>,<Y>{,<canShowEffect>};
      • makeitem2 <item id>,<amount>,"<map name>",<X>,<Y>,<identify>,<refine>,<attribute>,<card1>,<card2>,<card3>,<card4>{,<canShowEffect>};
      • makeitem2 "<item name>",<amount>,"<map name>",<X>,<Y>,<identify>,<refine>,<attribute>,<card1>,<card2>,<card3>,<card4>{,<canShowEffect>};
      • makeitem3 <item id>,<amount>,"<map name>",<X>,<Y>,<identify>,<refine>,<attribute>,<card1>,<card2>,<card3>,<card4>,<RandomIDArray>,<RandomValueArray>,<RandomParamArray>{,<canShowEffect>};
      • makeitem3 "<item name>",<amount>,"<map name>",<X>,<Y>,<identify>,<refine>,<attribute>,<card1>,<card2>,<card3>,<card4>,<RandomIDArray>,<RandomValueArray>,<RandomParamArray>{,<canShowEffect>};
      • makeitem4 <item id>,<amount>,"<map name>",<X>,<Y>,<identify>,<refine>,<attribute>,<card1>,<card2>,<card3>,<card4>,<grade>,<RandomIDArray>,<RandomValueArray>,<RandomParamArray>{,<canShowEffect>};
      • makeitem4 "<item name>",<amount>,"<map name>",<X>,<Y>,<identify>,<refine>,<attribute>,<card1>,<card2>,<card3>,<card4>,<grade>,<RandomIDArray>,<RandomValueArray>,<RandomParamArray>{,<canShowEffect>};

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      <item id> Integer The database ID of the item from item_db.yml.
      <amount> Integer The quantity or amount to add, remove, or check.
      "<map name>" String The name of the target map (e.g., "prontera").
      <X> Integer The X coordinate on the map.
      <Y> Integer The Y coordinate on the map.
      <canShowEffect> (Optional) Integer Boolean flag (1 = show item drop pillar effect if configured in item DB, 0 = no effect).
      "<item name>" String The English or Aegis name of the item from item_db.yml.
      <identify> Integer Identification state: 1 = identified, 0 = unidentified.
      <refine> Integer The refine (upgrade) level of the equipment (e.g., 0 to 20).
      <attribute> Integer Equipment broken state: 0 = normal (not broken), 1 = broken.
      <card1> Integer Item ID of the card or enchant in slot 1 (or 0 if empty).
      <card2> Integer Item ID of the card or enchant in slot 2 (or 0 if empty).
      <card3> Integer Item ID of the card or enchant in slot 3 (or 0 if empty).
      <card4> Integer Item ID of the card or enchant in slot 4 (or 0 if empty).
      <RandomIDArray> Array An array variable containing Random Option IDs.
      <RandomValueArray> Array An array variable containing Random Option values.
      <RandomParamArray> Array An array variable containing Random Option parameters.
      <grade> Integer The enchant grade constant (e.g., ENCHANTGRADE_NONE, ENCHANTGRADE_D .. ENCHANTGRADE_A).

      Constants & Options ⚙️

      Constant / Value Description
      ENCHANTGRADE_NONE No grade
      ENCHANTGRADE_D Grade D
      ENCHANTGRADE_C Grade C
      ENCHANTGRADE_B Grade B
      ENCHANTGRADE_A Grade A

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= makeitem, makeitem2, makeitem3, makeitem4 Demonstration NPC
//= Demonstrates how to use makeitem, makeitem2, makeitem3, makeitem4
//============================================================
prontera,150,150,4	script	MakeitemDemo	100,{
    mes "[MakeitemDemo]";
    mes "Event listener active.";
    close;

    // 0.5% chance to get +0 Valkyrie Shield [1]
        // with Neutral Resistance +10% and 5% damage reduction from Demi-Human or Player
        // when Valkyrie Randgris killed
        OnNPCKillEvent:
            if (killedrid == 1751 && rand(0,10000) > 9950) { // Valkyrie Randgris
                getmapxy(.@map$,.@x,.@y,BL_PC);
                setarray .@OptID[0],RDMOPT_ATTR_TOLERACE_NOTHING,RDMOPT_RACE_TOLERACE_HUMAN;
                setarray .@OptVal[0],10,5;
                setarray .@OptParam[0],0;
                makeitem3 2115,1,.@map$,.@x,.@y,0,0,0,0,0,0,0,.@OptID,.@OptVal,.@OptParam;
            }
            end;
}

      In this script:

      • The script defines an NPC object on prontera (or the target map) that triggers when a player interacts with it.
      • It invokes makeitem with the required arguments as specified in the rAthena scripting reference.
      • Any resulting state change, return value, or player/unit update is processed immediately within the active script execution context.
