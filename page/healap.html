      healap()

      What is healap? 🤔

      The healap() command restores (or subtracts) a specified amount of AP (Activity Points / Action Points) to the target/invoking character. AP is extensively utilized on rAthena servers by modern 4th Job class scripts to fuel high-tier visual master active skills.

      No Overflows: The command operates safely within job constraints. It will not allow a player's AP pool to exceed their natural maximum allowance, nor can negative indicators push it below zero!

      Syntax of healap? 📜

      • healap <ap>{,<char_id>};

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      <ap> Integer The number of Activity Points to alter:
      - Positive values (e.g. 10) grant points.
      - Negative values (e.g. -10) drain/consume points.
      <char_id> (Optional) Integer The database ID of the target character. Defaults to the currently attached invoking player if omitted.

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= AP charging & drainage station
//= Demonstrates positive and negative healap operations
//============================================================
prontera,164,180,4	script	AP Charger Station	99,{
    mes "^0000FF[AP Charger]^000000";
    mes "Greetings, master of the 4th Class arts.";
    mes "I manipulate client Activity Points (AP) flows.";
    next;
    
    set .@sel, select("Charge me with 50 AP:Drain 30 of my AP:Cancel");
    
    if (.@sel == 1) {
        // Restores 50 AP
        healap 50;
        specialeffect 733; // AP charging visual glow effect
        dispbottom "AP charging sequence complete: +50 AP added!";
    } 
    else if (.@sel == 2) {
        // Drains 30 AP
        healap -30;
        specialeffect 523; // Dark exhaust effect representing drainage
        dispbottom "AP drainage sequence complete: -30 AP removed!";
    }
    
    mes "^0000FF[AP Charger]^000000";
    mes "Flow transaction complete!";
    close;
}

      In this script:

      • On line 14, healap 50 adds exactly 50 AP to the character's active 4th Job pool, bounded by their class maximum.
      • On line 20, healap -30 acts as a negative cost command to consume their energy resources, replicating an in-game custom quest or training exercise mechanism.
