      unitskilluseid, unitskillusepos

      What are unitskilluseid, unitskillusepos? 🤔

      This is the replacement of the older commands, these use the same values for GID as the other unit* commands (See GID).

      Skill ID is the ID of the skill, skill level is the level of the skill. Cast time is the amount of seconds to add or remove from the skill. Use a positive value to add and negative value to subtract. Using 0 or no value will use the default skill cast time. For the position, the x and y are given in the UnitSkillUsePos.

      <cancel> defines if the cast can be interrupted when hit (true/false). CastCancel from skill_db.yml is the default value of <cancel>.

      If <Line_ID> is defined (positive number, default 0) the monster will say the message from Line_ID in mob_chat_db.yml when casting the skill.

      If <ignore_range> is true, the unit will ignore the skill range defined by the database. The default value is false. Attention! this setting does not work for all skills.

      Syntax of unitskilluseid, unitskillusepos 📜

      • unitskilluseid <GID>,<skill id>,<skill lvl>{,<target id>,<casttime>,<cancel>,<Line_ID>,<ignore_range>};
      • unitskilluseid <GID>,"<skill name>",<skill lvl>{,<target id>,<casttime>,<cancel>,<Line_ID>,<ignore_range>};
      • unitskillusepos <GID>,<skill id>,<skill lvl>,<x>,<y>{,<casttime>,<cancel>,<Line_ID>,<ignore_range>};
      • unitskillusepos <GID>,"<skill name>",<skill lvl>,<x>,<y>{,<casttime>,<cancel>,<Line_ID>,<ignore_range>};

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      <GID> Integer The unique Game ID (GID) of the target unit (monster, NPC, pet, homunculus, mercenary, or player).
      <skill id> Integer The numeric skill ID from skill_db.yml.
      <skill lvl> Integer The level of the skill to cast or grant.
      <target id> (Optional) Integer The Game ID or account ID of the target entity.
      <casttime> (Optional) Integer Specifies the <casttime> parameter for unitskilluseid.
      <cancel> (Optional) Integer <cancel> defines if the cast can be interrupted when hit (true/false).
      <Line_ID> (Optional) Integer Specifies the <Line_ID> parameter for unitskilluseid.
      <ignore_range> (Optional) Integer If <ignore_range> is true, the unit will ignore the skill range defined by the database.
      "<skill name>" String The AegisName of the skill from skill_db.yml (e.g., "AL_HEAL").
      <x> Integer The X coordinate on the map.
      <y> Integer The Y coordinate on the map.

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= unitskilluseid, unitskillusepos Demonstration NPC
//= Demonstrates how to use unitskilluseid, unitskillusepos
//============================================================
prontera,150,150,4	script	UnitskilluseidDemo	100,{
    mes "^0000FF[UnitskilluseidDemo]^000000";
    mes "Testing the unitskilluseid command.";
    next;

    unitskilluseid getcharid(3), 28, 10;
    mes "Executed unitskilluseid successfully!";
    close;
}

      In this script:

      • The script defines an NPC object on prontera (or the target map) that triggers when a player interacts with it.
      • It invokes unitskilluseid with the required arguments as specified in the rAthena scripting reference.
      • Any resulting state change, return value, or player/unit update is processed immediately within the active script execution context.
