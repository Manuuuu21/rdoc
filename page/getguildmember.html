      getguildmember

      What is getguildmember? 🤔

      This command will find all members of a specified guild and returns their names (or character id or account id depending on the value of "type") into an array of temporary global variables.

      Upon executing this,

      $@guildmembername$[] is a global temporary string array which contains all the names of these guild members. (only set when type is 0 or not specified)

      $@guildmembercid[] is a global temporary number array which contains the character id of these guild members. (only set when type is 1)

      $@guildmemberaid[] is a global temporary number array which contains the account id of these guild members. (only set when type is 2)

      $@guildmembercount is the number of guild members that were found.

      The guild members will be found regardless of whether they are online or offline. Note that the names come in no particular order.

      Be sure to use $@guildmembercount to go through this array, and not getarraysize, because it is not cleared between runs of getguildmember.

      If array_variable is set, the result will be stored to that variable instead using global variable.

      For usage examples, see getpartymember.

      Syntax of getguildmember 📜

      • getguildmember <guild id>{,<type>{,<array_variable>}};

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      <guild id> Integer The unique ID of the target guild.
      <type> (Optional) Integer The information or operation type constant/index to query or apply.
      <array_variable> (Optional) Array The script array variable to populate with results.

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= getguildmember Demonstration NPC
//= Demonstrates how to use getguildmember
//============================================================
prontera,150,150,4	script	GetguildmemberDemo	100,{
    mes "^0000FF[GetguildmemberDemo]^000000";
    mes "Testing the getguildmember command.";
    next;

    getguildmember getcharid(2);
    mes "Executed getguildmember successfully!";
    close;
}

      In this script:

      • The script defines an NPC object on prontera (or the target map) that triggers when a player interacts with it.
      • It invokes getguildmember with the required arguments as specified in the rAthena scripting reference.
      • Any resulting state change, return value, or player/unit update is processed immediately within the active script execution context.
