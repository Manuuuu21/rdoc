      getinventorylist()

      What is getinventorylist? 🤔

      The getinventorylist() command is a powerful diagnostic and inventory-handling script utility. It populates a pre-defined set of temporary character-specific variables and arrays with a complete, detailed dump of everything the character currently holds in their inventory.

      This command is incredibly useful for backing up, restoring, auditing, and cleaning player gear, or implementing item-specific search functions. No other command returns such a comprehensive dataset of cards, random modifiers, bounds, and refine metrics.

      Syntax of getinventorylist? 📜

      • getinventorylist({<char_id>});

      If an optional char_id is supplied, the command queries and populates inventory data for that specific character (assuming they are currently online). If omitted, it defaults to the active character currently invoking the script.

      Populated Array Variables 🧩

      When executed, getinventorylist() returns no values directly. Instead, it dynamically instantiates the following temporary, integer-based scope arrays on the character:

      Variable Array Name Detailed Description
      @inventorylist_count The total number of unique item stacks found in the inventory. Use this to bound your loops.
      @inventorylist_id[] The Item ID of each inventory item stack.
      @inventorylist_idx[] The exact inventory slot index of each item (crucial for exact deletion via delitemidx).
      @inventorylist_amount[] The stack amount of the item.
      @inventorylist_equip[] Indicates whether and where the item is equipped (using EQP_* constants). Returns 0 if unequipped.
      @inventorylist_refine[] Refinement value of the item.
      @inventorylist_identify[] 1 if the item has been identified, and 0 if unidentified.
      @inventorylist_attribute[] 1 if the item is broken (damaged), and 0 if intact.
      @inventorylist_card1[] ... @inventorylist_card4[] Four separate arrays storing IDs of slot-compounded cards, maker IDs (for custom weapons/items), or elemental details.
      @inventorylist_expire[] Unix timestamp of item expiration. Returns 0 if the item is permanent.
      @inventorylist_bound[] The bind type restriction status of the item (referencing BOUND_* constants).
      @inventorylist_enchantgrade[] Enchantment grade of the item.
      @inventorylist_option_id1[] ... @inventorylist_option_id5[] Ids representing random options/modifiers applied to the item.
      @inventorylist_option_value1[] ... @inventorylist_option_value5[] Values corresponding to respective random option slots.
      @inventorylist_option_parameter1[] ... @inventorylist_option_parameter5[] Parameters representing additional option factors.
      @inventorylist_tradable Returns 1 if the item is tradable, or 0 if restricted.
      @inventorylist_favorite Returns 1 if the player marked the item as a favorite, otherwises 0.

      ⚠️ Critical Loop Rule (Must Read!)

      Do NOT use getarraysize() to construct your loops over inventory lists.
      Temporary arrays instantiated by rAthena console scripts are not automatically cleared between distinct executions of the getinventorylist() command. If you previously fetched an inventory with 50 elements and now query one with 10 elements, the indices from 10 to 49 will still contain stale values!
      Always base your counter limits exclusively on @inventorylist_count!

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= Card & Unbinding Cleaner NPC
//===== By: rAthena AI Assistant ============================
//= Showcases getinventorylist() to cycle player inventories,
//= counts Carded Items, and allows removal by index.
//============================================================
prontera,150,190,4	script	Inventory Cleaner	909,{
    mes "^0000FF[Inventory Cleaner]^000000";
    mes "Greetings! I can extract card statistics from your inventory.";
    mes "Let me run a diagnostic sweep of your items.";
    next;

    // 1. Refresh inventory array elements
    getinventorylist();

    set .@carded_count, 0;

    // 2. Loop using @inventorylist_count (Never getarraysize!)
    for (set .@i, 0; .@i < @inventorylist_count; set .@i, .@i + 1) {
        // Any value inside card1-card4 represents a card slot, custom maker, or element
        if (@inventorylist_card1[.@i] != 0 || @inventorylist_card2[.@i] != 0 ||
            @inventorylist_card3[.@i] != 0 || @inventorylist_card4[.@i] != 0) {
            set .@carded_count, .@carded_count + 1;
        }
    }

    mes "^0000FF[Inventory Cleaner]^000000";
    mes "Sweep completed!";
    mes "You are currently holding ^00FF00" + @inventorylist_count + "^000000 distinct items.";
    mes "Out of those, ^FF0000" + .@carded_count + "^000000 items contain cards, enchants, or custom attributes.";
    next;

    mes "^0000FF[Inventory Cleaner]^000000";
    mes "Would you like to review card slots or exit?";
    if (select("Review Carded Items:Exit") == 2) {
        mes "Safe travels!";
        close;
    }

    // 3. Render a dynamic list of carded items
    for (set .@i, 0; .@i < @inventorylist_count; set .@i, .@i + 1) {
        if (@inventorylist_card1[.@i] != 0) {
            mes "^0055FFItem:^000000 " + getitemname(@inventorylist_id[.@i]) + " (Index: " + @inventorylist_idx[.@i] + ")";
            mes " -> Embedded Card Slot 1 ID: " + @inventorylist_card1[.@i];
        }
    }
    close;
}

      In this script:

      The showcase clean-up script showcases correct, robust handling of temporary lists:

      • We invoke getinventorylist() which populates arrays like @inventorylist_count and @inventorylist_id[] in memory.
      • We enforce the absolute gold rule of rAthena looping by using set .@i, 0; .@i < @inventorylist_count; set .@i, .@i + 1 instead of getarraysize, successfully bypassing potential side-effects from remaining stale data in previous checks.
      • We safely verify custom item properties and look up indices matching carded or elemental configurations.
