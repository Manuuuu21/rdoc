      roclass()

      What is roclass()? 🤔

      The roclass() function is the direct inverse of eaclass(). Given an encoded eA job bitmask value, it converts and returns the corresponding standard Ragnarok Online (RO) numeric class ID.

      Because multiple classes can sometimes share similar eA representations or masks (for example, Bards and Dancers share the same base mask EAJ_BARDDANCER), a gender argument is supported. The function defaults to checking the gender of the invoking player, or defaults to Male if no player character is attached.

      It returns -1 if there is no valid standard class representing the specified eA job-number (such as requesting a baby variation of a Taekwon class which does not exist in the Ragnarok databases).

      Syntax of roclass() 📜

      • roclass(<eA job number>{, <gender>})

      Example Usage 💡

      Example Code:
      prontera,150,150,4	script	eA to RO Resolver	99,{
    // Extract the calling player's eA job-number bitmask
    set .@eac, eaclass();
    
    // Check if the character is already a rebirth class
    if (.@eac & EAJL_UPPER) {
        mes "You have already reborn!";
        close;
    }
    
    // Add the rebirth flag (EAJL_UPPER) to the eA configuration
    set .@eac_rebirth, .@eac | EAJL_UPPER;
    
    // Resolve what the standard RO Class ID of the rebirth version would be
    set .@ro_rebirth_id, roclass(.@eac_rebirth);
    
    if (.@ro_rebirth_id != -1) {
        mes "Your future Reborn class name is: " + jobname(.@ro_rebirth_id);
    } else {
        mes "Your current job class does not have an official rebirth counterpart.";
    }
    close;
}

      In this script:

      • On line 3, eaclass() fetches the current class's eA bitmask configurations.
      • On line 12, .@eac | EAJL_UPPER sets the rebirth status bit on the eA structure.
      • On line 15, roclass(.@eac_rebirth) maps the new bitmask back to a standard RO internal numeric job index so that it can be inspected or applied.
