      addrid()

      What is addrid? 🤔

      The addrid() command lets you attach other players (RIDs) to the current script execution thread **without detaching** the initial invoking character. This enables broadcasting rewards, global checks, area actions, or full party updates from a single script scope.

      Syntax of addrid? 📜

      • addrid(<type>{,<flag>{,<parameters>}})

      Syntax Parameter Explanation 🧩

      Parameter Type Description
      <type> Integer Determines which group of players is attached (see mapping below).
      <flag> (Optional) Integer Filters matching targets:
      0 - Always attach player targets.
      1 - Skip players active in dialog scripts.
      <parameters> (Optional) Variable Additional context required by specific types (e.g. party ID, map name, or area limits).

      Supported Attachment Types 📍

      Type Value Targets Selected Required Arguments / Parameters
      0All players currently logged into the server.None
      1All players on the map of the invoking character/NPC.None
      2Members of a specific party.<party_id>
      3Members of a specific guild.<guild_id>
      4Players inside rectangular map coordinates.<x0>,<y0>,<x1>,<y1>
      5All players situated on a explicitly specified map."<map_name>"
      6Members of a specified battleground match.<battleground_id>
      7Members of a specified clan.<clan_id>

      Example Usage 💡

      Example Code:
      //===== rAthena Script =======================================
//= Map Event Reward Dispenser
//= Demonstrates addrid() usage to reward a whole map
//============================================================
prontera,150,160,4	script	Reward Center	115,{
    mes "^0000FF[Reward Center]^000000";
    mes "Would you like to trigger the Map Activity Pouch?";
    next;
    
    if (select("Yes, proceed!:No, exit") == 2) {
        close;
    }
    
    // Attach all players in the invoking character's map (Type 1)
    // Avoid busy dialog sessions using flag 1
    if (addrid(1, 1)) {
        getitem 501, 5; // Gives 5 Red Potions to EACH player on the map!
        dispbottom "Congratulations! You received a map event participation reward!";
    }
    
    close;
}

      In this script:

      The Reward Center performs high-concurrency loops:

      • The command addrid(1, 1) on line 12 finds players sharing the map location of the current script trigger and binds their sessions.
      • Because they are bound, the single getitem and dispbottom invocations are executed across every matched player simultaneously!
