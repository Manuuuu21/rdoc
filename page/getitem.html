      getitem, getitem2, getitem3, getitem4

      What's the getitem family? 🤔

      The getitem commands grant a specified quantity of items definition directly to the target character's inventory bag.

      If an optional account ID is passed, and that target player is currently active online, the reward is put into their storage bag. If they are offline, nothing happens.

      Syntax 📜

      1. getitem (Standard)

      Standard item delivery method using standard item DB parameters.

      • getitem <item id>,<amount>{,<account ID>};
      • getitem "<item name>",<amount>{,<account ID>};

      2. getitem2 (Advanced Compound)

      Grants weapons/armors pre-equipped with customize refine values, card slots, identification status, and attributes.

      • getitem2 <item id>,<amount>,<identify>,<refine>,<attribute>,<card1>,<card2>,<card3>,<card4>{,<account ID>};
      • getitem2 "<item name>",<amount>,<identify>,<refine>,<attribute>,<card1>,<card2>,<card3>,<card4>{,<account ID>};

      3. getitem3 (Random Options Support)

      Advanced extension of getitem2 that adds customizable Item Random Options parameters mapping.

      • getitem3 <item id>,<amount>,<identify>,<refine>,<attribute>,<card1>,<card2>,<card3>,<card4>,<RandomIDArray>,<RandomValueArray>,<RandomParamArray>{,<account ID>};

      4. getitem4 (Grade Support)

      The maximum grade system version adding custom ENCHANTGRADE settings on top of random item parameters.

      • getitem4 <item id>,<amount>,<identify>,<refine>,<attribute>,<card1>,<card2>,<card3>,<card4>,<grade>,<RandomIDArray>,<RandomValueArray>,<RandomParamArray>{,<account ID>};

      Syntax Parameter Explanation 🧩

      • identify: 1 = Identified, 0 = Unidentified (unappraised magnifying glass state)
      • refine: The refine plus level. Will not exceed the server's defined maximum refine capability.
      • attribute: 1 = Broken, 0 = Normal / Standard unbroken.
      • card1..card4: Card item ID integers to pre-socket into available slots.
      • grade: Enchant Grade constant (e.g. ENCHANTGRADE_D)
      • Random Option Arrays: Arrays storing random bonus ID mappings, value factors, and custom params.

      Examples 💡

      Example 1: Basic Reward NPC
      //===== rAthena Script =======================================
//= Name: Basic Reward NPC
//===== By: rAthena AI Assistant ============================
//= Function: Demonstrates getitem
//============================================================

prontera,150,150,4	script	BasicRewardNPC	767,{
    mes "[Reward NPC]";
    mes "Here is a simple gift for you.";
    getitem 501, 5; // Gives 5 Red Potions
    close;
}

      In this script:

      • getitem 501, 5 adds 5 Red Potions (ID 501) directly to the attached character's bag without any compound socket values.
      Example 2: CustomItemNPC 
      //===== rAthena Script =======================================
//= Name: Custom Item NPC
//===== By: rAthena AI Assistant ============================
//= Function: Demonstrates getitem2
//============================================================

prontera,150,150,4	script	CustomItemNPC	767,{
    mes "[Custom NPC]";
    mes "I have a special +5 Knife for you.";
    // ID 1201 (Knife), Amount 1, Identified 1, Refine 5, Broken 0, Card1 4001 (Poring Card), Card2 0, Card3 0, Card4 0
    getitem2 1201, 1, 1, 5, 0, 4001, 0, 0, 0;
    close;
}

      In this script:

      • The attached player will immediately receive one +5 Knife [3] that is already identified, in perfect condition (not broken), and has a Poring Card (ID 4001) pre-equipped in its first slot, while the other slots remain empty.
      Example 3: Random Options & Grades
      //===== rAthena Script =======================================
//= Name: Random Option NPC
//===== By: rAthena AI Assistant ============================
//= Function: Demonstrates getitem3
//============================================================

prontera,154,150,4	script	RandomOptionNPC	767,{
    mes "[Random NPC]";
    mes "Here is a dagger with a random option.";
    setarray .@opt_id[0], 1001; // Example Random Option ID
    setarray .@opt_val[0], 5;
    setarray .@opt_param[0], 0;
    getitem3 1201, 1, 1, 0, 0, 0, 0, 0, 0, .@opt_id, .@opt_val, .@opt_param;
    close;
}

//===== rAthena Script =======================================
//= Name: Graded Item NPC
//===== By: rAthena AI Assistant ============================
//= Function: Demonstrates getitem4
//============================================================

prontera,156,150,4	script	GradedItemNPC	767,{
    mes "[Graded NPC]";
    mes "Here is a high-grade dagger.";
    setarray .@opt_id[0], 0;
    setarray .@opt_val[0], 0;
    setarray .@opt_param[0], 0;
    // Grade A
    getitem4 1201, 1, 1, 0, 0, 0, 0, 0, 0, ENCHANTGRADE_A, .@opt_id, .@opt_val, .@opt_param;
    close;
}

      In this script:

      • In this script, two distinct NPCs are defined to demonstrate advanced item-creation commands in rAthena: the first NPC, RandomOptionNPC, utilizes the getitem3 command to award the player a Knife (1201) embedded with a specific random option (ID 1001, value 5, and parameter 0) defined via scope arrays, while the second NPC, GradedItemNPC, uses the getitem4 command to grant a Knife with an elite ENCHANTGRADE_A (Grade A) status while keeping its random option slots empty.
